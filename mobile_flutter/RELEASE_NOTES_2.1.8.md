# UniWay 2.1.8 測試版｜清爽交換旅程

- 旅程首頁突出目前可做的下一步，並保留原有收藏、文件與時程入口。
- 底部導覽加入「旅程、學校、申請、論壇、我的」文字標籤。
- 學校列表新增底部篩選面板，可以依既有國家及收藏條件預覽結果、套用或重設。
- 申請頁以實際必填欄位完成狀態呈現進度，並提供下一份待準備文件的入口。
- 論壇卡片顯示文章主題、已有的回覆數及進入討論的提示。

Android 套件為 `tw.uniway.app`，最低支援 Android 7；版本號為 `2.1.8+22`。使用與既有測試版相同的簽章，並確認簽章一致後，才能直接覆蓋安裝 2.1.7。APK 連接既有的 UniWay 正式服務。

這是介面更新，申請資格、名額及截止日期仍以各校官方公告為準。
