# UniWay 2.1.4 測試版：圖示導覽與三步交換準備

## 本次更新

- 首頁用「找學校 → 備文件 → 排時程」帶你準備交換。
- 減少重複文字，增加圖示與短標籤；需要教學時再點「？」。
- 學校可依國家、收藏篩選，點卡片直接看完整資料。
- 申請頁改成六個圖示工具，文件清單更容易找到。
- 論壇保留完整討論功能，發文按鈕放在底部；帳號設定改用可搜尋的大學選單。
- 延續玻璃卡片風格，統一字體、圓角與間距，支援放大文字。

## 安裝

1. 下載本頁 **UniWay-2.1.4-preview.apk**，在 Android 手機開啟。
2. 依系統提示允許瀏覽器或檔案管理員安裝，確認更新即可，不必先解除安裝舊版。
3. 已有 2.1.3：可到「我的 → 檢查更新」，或等待 App 下次自動檢查提醒。
4. 下載後仍需開啟 APK 並由 Android 確認安裝。2.1.2 尚無更新檢查，請先手動下載這次更新。

Android 7.0 以上；套件 `tw.uniway.app`，版本 2.1.4 / 18，沿用相同簽章。
APK SHA-256：`2aa48be00a5ea51c0fa104fe17eac551b4a9e69428315c9af372c8b8c5655368`。

沿用 https://app.uniway-tw.com/ 的帳號與服務。Firebase 遠端推播仍待設定；
更新提醒不依賴 Firebase。實機 Google 登入及跨裝置操作仍待驗收。本次沒有新增大學資料查核。
