本批不需要資料庫schema、migration、Storage bucket或資料移轉。不要執行 update.ps1／03-start.ps1／04-apply-migrations.ps1；它們會擴張至角色密碼、全部migration及bucket。本任務也不使用舊Render／雲端Supabase。舊雲端缺migration不能推論成現在本地也缺；本地實際migration清單不在本批核實範圍。

先決條件與決策：父端須核准本PR確切commit及五項既有main測試問題的處理方式。臺大104項重點、25瀏覽器及60靜態測試通過；完整全套仍不是全綠。不要順帶拉入已暫停的中央／跨校分支。確認主機可重建app及短暫重啟窗口、原container imageID、現有.env/CA/compose設定和可用磁碟。正式憑證不輸出、不新建。

## 可採的有限操作（交由父端核准後執行）

以已測commit為建置來源，Git切换或合併由父端依流程處理。`$TargetSha`應是回報中完整40位commit，不能只有分支名；先確認working tree乾淨、`git rev-parse HEAD`恰好等於它。保留原imageID並以不覆蓋舊備份的唯一tag保存回退映像。只有app會重建／重啟，DB／REST／Storage／gateway不操作。

在repo root，以下示意使用現有Compose與.env；不要印出展開後的完整compose config或秘密：

```powershell
$TargetSha = '<父端核准的完整已測commit>'
if ((git rev-parse HEAD).Trim() -ne $TargetSha) { throw 'checkout is not the approved commit' }
$OldContainer = docker compose -f deploy/selfhost/docker-compose.yml --env-file deploy/selfhost/.env ps -q app
$OldImage = docker inspect --format '{{.Image}}' $OldContainer
$BackupTag = 'uniway-app:before-ntu-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
docker tag $OldImage $BackupTag
if ($LASTEXITCODE -ne 0) { throw 'could not retain prior app image' }
docker build --label "org.opencontainers.image.revision=$TargetSha" -t uniway-app:local -f Dockerfile .
if ($LASTEXITCODE -ne 0) { throw 'app image build failed' }
docker compose -f deploy/selfhost/docker-compose.yml --env-file deploy/selfhost/.env up -d --no-build --no-deps app
if ($LASTEXITCODE -ne 0) { throw 'app recreation failed' }
```

這是依現有Dockerfile／Compose／entrypoint推導的最小操作，沒有在正式主機執行過。image build可能需要下載依賴／基礎映像；不使用新的付費服務。`--no-deps`使既有依賴不重啟，entrypoint只建立app內CA bundle後執行既有服務command，未呼叫migration或bucket腳本。
