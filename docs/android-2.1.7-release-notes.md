# UniWay 2.1.7 測試版｜明亮交換旅程

- 暖白背景、藍綠主色、清楚的圖示與短標籤，首頁、詳細頁、表單與小工具風格一致。
- 首頁以「下一步」與個人準備清單為主，加入旅行插圖與工具箱。
- 找學校改成大照片卡片，保留搜尋、國家篩選與收藏；長清單按需載入畫面。
- 申請頁顯示實際文件準備進度；論壇錯誤提示留在送出按鈕附近，失敗時保留草稿。
- 四款淺色 Widget：交換總覽、出發倒數、準備清單、準備進度。
- 底部保留純圖示導覽，支援長按提示與螢幕閱讀器標籤。

下載 `UniWay-2.1.7-preview.apk` 後開啟安裝。舊版可直接覆蓋更新，無須解除安裝。
也可在舊版「我的 → 檢查更新」取得新版。Android 7.0 以上；版本 `2.1.7+21`。

參考 [UI/UX Pro Max skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/.claude/skills/ui-ux-pro-max/SKILL.md)、
[IDP Live](https://www.idp.com/idp-live-app/?lang=en) 與 [Erasmus+ App](https://hello.erasmusapp.eu/) 的學生旅程和申請規劃方式。

沿用同一套正式帳號與服務。Firebase 遠端推播仍待設定；本次沒有新增大學資料查核。
iOS 共用介面與 Widget 同步更新，裝置版、模擬器版及啟動檢查已通過 [雲端建置](https://github.com/blizzard-new/abroad/actions/runs/40128312769)。
附件 `UniWay-iOS-unsigned-app.zip` 與 `UniWay-iOS-simulator.zip` 僅供開發使用；尚無 Apple 簽署設定，不能直接安裝到一般 iPhone。
