# 臺大第三校整合

2026-10-08依使用者指示將臺大加入Web與共用API。這是程式與資料整合紀錄；正式主機部署需依專案部署流程另外執行。

## 可使用的內容

- 選校入口、學校搜尋與帳號校別支援國立臺灣大學、臺大、台大、NTU等名稱；校級名單288項可搜尋、篩選與查看詳情。
- 校級116-1甄選時程、學籍／成績及語組規則、11項含條件式文件、費用與希望出航獎學金。
- 288筆合作校流程、生活資訊參考與官網來源；11校補充來源查核含適用範圍、版本差異及待確認事項。
- 管理、法律、工學、電機資訊四院的院級甄選摘要各自列出來源與截止日，獨立於校級規則。
- GPA與班排名欄位、研究生免校內成績門檻；TOEFL舊制120分與新制6分分開。百分制平均不換算成GPA，合作校TOEFL舊分數不自行換算成新制。
- 六種個人文件準備工具，清除長庚官方表格編號、下載網址及其他校別的行前／返國期限。正式推薦表與研究生推薦信須依臺大系統辦理。

## 來源與限制

校級簡章：[116-1國際交換學生甄選簡章](https://studyabroad.ntu.edu.tw/wp-content/uploads/2026/07/116-1-Selection-Guidelines_CH.pdf)，2026-10-07取得，PDF第2頁明列11月至12月的臺灣時間；第一階段選填及錄取報到從成績／錄取公布的16:00起，沒有推算開放時分。

名單：[臺大出國交換學校一覽表，第1學期](https://oia.ntu.edu.tw/outgoing/school.list/semester/1)。2026-10-08回傳HTTP200，仍為288項、282項本期名額空白、6項零名額；查核回執保存於`official_data/ntu/list_verification.json`。合約名額、歷史詳情名額與當期甄選名額分開，沒有把前兩者填進當期欄位。

零名額為西北大學、喬治梅森大學、夏威夷太平洋大學、夏威夷大學希羅分校、紐約州立大學阿爾伯尼分校與坎特伯雷大學。介面顯示「116-1零名額／本期未開放」。其餘282項顯示「合作備查／本期名額待公告」，可加入志願規劃、查看推薦及設為待確認目標；不表示已開放申請。

補助：[116-1希望出航申請公告](https://studyabroad.ntu.edu.tw/wp-content/uploads/2026/09/116學年度第1學期-國立臺灣大學希望出航出國交換學生獎學金-申請公告.pdf)。金額、經濟身分、重複領取限制及截止日依公告，不保證獲獎。

合作校本期名額及全部規定仍未完整核實；流程保持`pending_review`／`needs_confirmation`、`published_at=null`，不啟用待確認的合作校截止提醒。生活資訊來源有舊年度、無年份或版本衝突者保留原說明；空缺寫為「尚未取得並核對」，不推論官網未公開。臺大學生心得目前保留官方目錄來源，未把目錄當作已讀取的心得全文。排名、城市、校園照片不猜填。

五校名稱尾端共用的「E交換學生計畫、V訪問學生計畫」是計畫註記。校名識別會保留前方的學校名稱，避免五所不同學校共用資料。

## 可重建的資料匯入

執行環境直接讀取追蹤在Git內的`src/exchange_info/official_data/ntu/`。Git也保存了完整匯入所需的13份來源輸入，壓縮於`sources/ntu/2026-10-08-import.json.gz`（約1.7 MB）。離線重建及比對不需要先前工作區或網路：

```bash
python scripts/build_ntu_catalog.py --output-dir /tmp/ntu-rebuild
```

更新來源時仍可提供外部研究資料目錄：

```bash
python scripts/build_ntu_catalog.py \
  --candidates-dir /path/to/ntu-candidate/candidate \
  --verification-dir /path/to/ntu-current-verification/candidate \
  --list-verification /path/to/ntu-list-refresh.json
```

腳本用既有Pydantic模型驗證合作校、流程、生活資訊、官網研究、搜尋頁與儀表板格式。來源快照保留原始候選／授權／發布旗標，`import_provenance.json`記錄快照SHA-256、原始校內規則旗標、接入授權及查核狀態。匯入授權不等於內容審核通過；再次匯入仍保留未核實欄位與提醒限制。

## PR審查修正

- 推薦納入282項名額待公告的合作校，全部保留資格待確認；官方6項零名額不納入候選。
- 志願清單與目標選校允許待公告名額。參考流程可預覽；待確認內容不能透過此預覽加入日曆或啟用截止提醒。已核准流程原有的日期與訂閱檢查仍適用。
- 新制TOEFL沒有合作校可解析門檻時回傳待確認，長庚／臺北大學不再顯示`NaN`。臺大校內語組的推薦與資格評估使用同一函式，未達單一英語測驗門檻仍需核對其他可用證明。
- `home_rules.json`提供結構化校內規則，儀表板傳給前端，避免成績門檻與語言分數在多處重複計算。排名必須大於0；前後端均排除在職專班。系所輸入與下拉選單分別保留固定元素，切校不再複製不適用的HTML屬性。
- 流程中與合作校詳情重複的原文改為詳情參照，原文仍保存在合作校資料；省略序列化的預設值後，臺大流程檔由7,025,477 bytes降為4,042,187 bytes。相同環境的首次載入測量為851筆、0.98→0.91秒、最大RSS約168→157 MiB；單次測量僅用於記錄，不保證正式主機的效能。
- 補上`20261008130000_ntu_school_board.sql`，僅新增正確臺大校名搭配`ntu`討論板的規則。正式資料庫尚未套用，詳見[論壇migration與核准範圍](ntu-forum-migration.md)。
