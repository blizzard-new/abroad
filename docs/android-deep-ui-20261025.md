# Android 2.1.5：深層頁面與表單一致化

沿用 2.1.4 的主頁設計，依使用者指定的
[mobile-app-ui-design](https://github.com/ceorkm/mobile-app-ui-design) 整理深層頁面。
本次只修改 Flutter 顯示與操作配置、測試及交付文件；沒有新增大學資料查核、修改官方資料或部署後端。

## 修改範圍

- 共用頁面：一致的返回列、最多 600px 的閱讀寬度、鍵盤滑動收起、字體、圓角、對話框與底部操作列。
  窄螢幕或放大文字時，雙按鈕自動改為上下排列。
- 文件表單：縮短草稿狀態，保留敏感欄位與附件的保存限制；欄位分成填寫內容、附件、確認事項。
  儲存與 PDF 操作固定於底部。表單保持掛載，捲至送件資訊後仍會驗證全部必填欄位。
  官方格式、填寫說明、雲端附件引用、簽名、核章、送件與來源保留。
- 申請設定、共用資料、列印包：固定儲存／匯出按鈕；設定分組及欄位圖示；進度與份數改為適合窄螢幕的排列。
- 學校詳情：圖片與完整校名分開排列，以圖示切換重點、流程、生活、心得、社群。
  收藏與官方來源固定於底部；完整資料、來源、資格與資料限制保留。
- 交換預算與資格初判：按用途分組、增加輸入圖示、固定主要操作，保留既有計算及資格提示。
- 文件檢查、改寫與申請顧問：精簡重複頁首，移除固定高度的裝飾照片區，主要動作固定於底部。
  原文隱私、AI 選項與結果限制提示保留；沒有新增或執行外部資料查核。
- 論壇文章、發文與回覆：一致的頁面框架、圖示資訊、固定回覆／送出操作，保留帳號變更防護與伺服器權限。
- 校別社群、日曆、小工具、通知及帳號驗證：統一字體與卡片，縮短指引；社群選項可換行，日曆摘要隨內容增高。

## 驗證紀錄

- Flutter unit/widget tests：110 項通過，包含新增 10 項深層頁面測試。
- 新測試以虛構資料驗證 320px／2 倍字體下的設定、共用資料、列印包、預算、資格初判、顧問、文件檢查、改寫，
  以及學校詳情各區、來源與收藏；沒有因測試擴充學校資料查核。
- 360px／1.4 倍字體下填寫並儲存未完成草稿，捲至頁尾後 PDF 必填驗證仍有效。
- 既有安全草稿、帳號隔離、同步衝突、日曆與論壇測試通過。
- Analyze 沒有 error/warning；4 個既有 unnecessary_brace_in_string_interps style info 仍保留。
- Android 模擬器整合測試：新發文／回覆畫面操作成功，隔離後端寫入後由另一 API client 讀回相同內容；
  PackageInfo 取得 2.1.5 / 19，模擬未來 2.1.6 的更新提醒開啟正確附件 URL。沒有發布假的未來版本。
- 最終簽署 APK 已檢視學校詳情、文件表單及捲動、共用資料及鍵盤、列印包、文件檢查、交換預算；返回與固定操作列正常。
- 公開發布後，2.1.4 的「我的 → 檢查更新」顯示 2.1.5，下載按鈕以 Android VIEW intent 開啟正確 APK URL。
  同一模擬器以 `adb install -r` 覆蓋為 2.1.5 / 19 後冷啟動成功；這不是實體手機系統安裝畫面的驗收。

公開下載、正式簽章、實際 release 畫面與覆蓋安裝結果記於
`android-public-download-2.1.5-20261025.json`。
實體手機 Google 登入與跨裝置操作仍待使用者驗收，Firebase 遠端推播仍待設定。
