# 交換合作校名單與帳號權限

> **2026-10-03 更新：下面 2026-09-29 的規則已被取代。** 為了先上線免費網頁版，兩校（長庚、臺北大學）的合作校名單、流程、文件與生活情報改為訪客不登入即可讀取，也不再依校籍限制範圍；帳號只決定預設開哪一所。帳號只開放 Google 登入；Google 已驗證信箱為 `cgu.edu.tw`／`ntpu.edu.tw` 時自動帶入學校，其他人登入後自選。信箱網域與自選學校都不算驗證在學：學校板發文與用校名署名仍須學生證等校籍驗證，保存進度與計畫只需 Google 帳號。**同日稍晚再更新：所有討論板（含兩校板）的發文、留言、按讚也只需 email 已驗證的 Google 帳號**（用校名署名、問答、分享心得、即時聊天仍須驗證在學身分）。管理員跨校與發文權限不變。目前規則見 [`launch-plan-2026-10-03.md`](launch-plan-2026-10-03.md)，對應測試是 `tests/test_catalog_access.py` 與 `tests/test_open_catalog_signup.py`。以下保留原文作為歷史紀錄。

2026-09-29，Web 與 API。

- 訪客必須登入才能取得交換合作校資料。
- 一般帳號的名單範圍依 `student_status_verified` 與 `verified_university` 決定。未完成校籍驗證時顯示驗證入口。
- 自行修改 `home_university`、網址、顯示名稱或前端儲存資料，不會取得其他母校名單。
- 平台管理員由伺服器的 `EXCHANGE_PLATFORM_ADMIN_ACCOUNT_IDS` 指定，值為逗號分隔的帳號 ID。此設定不能由公開個人資料 API 修改。
- 管理員可切換所有已支援母校的名單；一般帳號鎖定自己的已驗證母校。
- 受保護的名單、單校流程、生活情報、文件與顧問來源回應皆不允許共用快取。`/universities` 僅公開母校的基本資料，不提供合作校名單。
- 公共板與語言學校板需要已開通電子郵件權限；校級板需要對應校籍，平台管理員可在所有已支援校級板發文與留言。發言身分必須屬於登入帳號，停權限制仍適用。

既有本機臺北大學管理員已以 `admin_approval` 開通校籍權限並設定 subscription 方案；未改動既有密碼，也未將任何真實申請標記為已送件。此帳號的本機啟動設定與登入說明仍位於 `%LOCALAPPDATA%\UniWay\ntpu-local-admin`。啟動時使用其中的 `start-preview.ps1` 以載入管理員 ID；一般未設定此環境變數的啟動方式不會自動授予跨校權限。

所有學校的申請流程步驟改為預設收合。使用者點選步驟標題後才展開，支援滑鼠與鍵盤。

驗證：`tests/test_catalog_access.py` 的 16 項隔離資料測試、`tests/test_auth_api.py` 的 24 項測試通過。涵蓋訪客拒絕、一般學生跨校拒絕、管理員跨校存取、直接連結、假冒角色欄位、並行請求隔離、發文與留言權限。實際預覽驗證管理員可讀取長庚 77 所、臺北大學 203 所，訪客 API 回應 401，發文表單可開啟且未發布測試文章。學校流程頁實測為六步皆收合，點選第一步只有第一步展開。

本次未執行整個專案測試套件，未部署到遠端或修改原生 App。既有 API 檔案中四行無關的尾端空白仍存在，`git diff --check` 會報告這些既有項目。
