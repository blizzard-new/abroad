# UniWay 2.1.3 測試版：論壇與更新提醒

## 本次更新

- App 啟動或回到前景會檢查新版；有新版時跳出提醒，按「下載更新」即可開啟 APK 下載。也可在「我的」手動檢查。
- 底部新增「論壇」：看板、主題篩選、關鍵字搜尋、分頁文章、完整文章與樓中樓回覆。
- 使用和網站相同的帳號與論壇內容，可匿名發文、回覆、刪除自己的內容及檢舉不當內容。
- 訪客可閱讀公共看板；登入並完成信箱驗證後，依網站相同權限查看校板及參與討論。
- 登出或切換帳號後會清除舊論壇畫面，避免使用錯誤帳號的發文身分。

## 安裝方式

1. 下載本頁的 **UniWay-2.1.3-preview.apk**，不要下載 Source code。
2. 在 Android 手機開啟檔案；首次安裝時，依系統提示允許目前的瀏覽器或檔案管理員安裝 App。
3. 已安裝 2.1.2 者可直接覆蓋更新，不必解除安裝。2.1.2 沒有檢查版本功能，這一次需手動安裝；2.1.3 起才會提醒後續新版。
4. 後續點「下載更新」後，仍需開啟下載完成的 APK 並依 Android 提示確認安裝。

Android 7.0 以上；套件 `tw.uniway.app`，版本 2.1.3 / 17，延用相同簽章。
