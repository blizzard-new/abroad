## 維護規則

1. 規格新增、刪除或拆分時，必須同一提交更新本矩陣與完整性測試。
2. API request、response、enum、錯誤狀態或權限邊界變更時，必須更新 `docs/api/openapi.json`，並在 code review 說明是否為 breaking change。
3. 自動測試通過不能把「待人工」直接改為「已實作」；官方來源、年度、期限與雙審證據只能由真人查核完成。
4. LAI-00～LAI-03 完成不得自動解除產品 AI `paused`；LAI-04 之後、production、Flutter 與原生 App 都需要各自的使用者明確新決定。
