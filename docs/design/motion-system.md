# UniWay Web 動態設計

讓操作像旅行一樣，有出發、抵達與完成的節奏。動態負責交代狀態改變；內容與操作本身不等待動畫。

## 共用節奏

| 用途 | 時間 | 表現 |
| --- | --- | --- |
| 按壓 | 110 ms | 縮至 97.5%，放開復原 |
| 狀態確認 | 160 ms | 收藏、追蹤、選取輕微放大再復原 |
| 頁面、分頁、展開 | 240 ms | 頁面淡入，標題移動 8 px；收合區平順改變高度 |
| 彈窗 | 320 ms | 淡入、上移 14 px，縮放 98.5% → 100% |
| 地圖定位 | 700 ms | 地球平順移至所選目的地 |

一般曲線為 `cubic-bezier(.2,.75,.25,1)`，進場為 `cubic-bezier(.16,1,.3,1)`。變數集中在 `src/exchange_info/static/motion.css`。

## 各區域行為

- 首頁：討論區標題輕輕進場；看板在滑鼠移入時浮起 2 px。
- 全站導覽：目前頁面有短底線；新頁淡入，返回的標題從左側 8 px 回到原位。還原捲動位置時不移動標題。
- 留學攻略：四階段短暫依序進場；FAQ 使用原生 details 展開與收合。
- 學校搜尋與收藏：每次結果更新，僅畫面內最多六個項目進場，間隔 18 ms。表格只淡入，不移動資料列；相同結果的重新繪製不重播所有卡片。
- 地圖：地球定位沿用共用時間；地圖與清單切換有短淡入，所屬學校光圈只播放兩次。
- 指南首頁（`/guides`）：四個階段在 1024 px 以上依捲動位置標示目前階段（視窗中線所在的階段），該階段的說明展開，卡片固定在右欄；切換很快：新的一組 140 ms 淡入並上移 4 px，離開的一組約 90 ms 就退場（變數 `--stage-speed`）。點階段或用鍵盤聚焦到其他階段的卡片，會把該階段捲到視窗中央；其他階段的卡片只是淡出，仍可用 Tab 到達。手機、窄視窗、關閉 JavaScript 與列印時是照順序堆疊的一般內容，每張卡片只出現一次。
- 申請指南（`#guide=how-to-use`）的「照階段往下走」：四個階段做成一排卡片，同一時間只展開一張（寬度以 300 ms 過場；手機改成直式）。展開的那張每 8 秒換下一張，但只在「卡片在畫面內、分頁可見、滑鼠沒停在卡片上、焦點不在卡片內、讀者沒按暫停」時才會動；讀者自己點某張卡片就停止自動播放，要按「繼續自動播放」才會再動；開啟「減少動態效果」時完全不自動播放、也不顯示暫停鈕。展開那張的進度條是剩餘時間的提示。卡片文字就是該節原本的四個步驟，所以搜尋仍找得到。
- 社群心得（`#forum` 心得檢視）：「學長姐投稿精選」只顯示作者同意公開、且已通過審核的心得摘要，資料來自 `GET /experience-stories`。它只在讀者操作時移動（箭頭、滑動或聚焦後按方向鍵），不自動播放；沒有核准內容時整區不顯示，不放示範或佔位內容。
- 學校介紹：資訊分頁輕淡入；沿用目的地章與完成章的旅行造型。
- 申請工具、帳號、社群：選單及彈窗進場、表單焦點與選取回饋共用節奏；資格、顧問、文件、行事曆與通知等結果區共用短進場。
- 載入與錯誤：骨架緩慢明暗變化，顧問保留載入狀態與一次完成動作；錯誤不抖動，訊息直接可讀。

## 行為與無障礙

- 不延遲導覽、存檔、焦點、Escape 或關閉視窗，不增加額外點擊步驟。
- 快速切頁會取消前一頁動態；隱藏或移除元素會取消動態。頁面切到背景時停止裝飾動畫。
- 支援作業系統「減少動態效果」，包括開啟中的偏好切換：關閉 CSS 與 JS 動態、地圖過渡和視差，程式捲動立即到位。
- 不對整個頁面施加位移，避免改變黏附元件或返回時的捲動位置。
- 僅在滑鼠等精確指標提供 hover 浮起；觸控沿用按壓回饋。
- 動態程式未載入時保留正常導覽與操作；較舊瀏覽器的 details 直接展開收合。

`motion.js` 使用原生 Web Animations API，監看已知內容區域及可見狀態；不讀寫使用者資料，不引入動畫套件。舊圖示的路徑變化保留，重複的整頁／圖示進場由共用層取代。

details 高度過渡以 `@supports` 限定瀏覽器支援；參考 [details 樣式](https://developer.chrome.com/blog/styling-details) 與 [auto 高度過渡](https://developer.chrome.com/docs/css-ui/animate-to-height-auto)。

## 驗證

`tests/e2e/test_guide_stage_scroll.py`、`tests/e2e/test_stage_deck.py` 與 `tests/e2e/test_story_carousel.py` 分別涵蓋指南階段捲動（寬／窄視窗、無 JavaScript、鍵盤聚焦、減少動態）與四階段卡片（自動播放、暫停、選卡片後停止、懸停與焦點、不在畫面內、減少動態、不堆疊計時器）及心得輪播（只顯示已核准內容、匿名不具名、不自動播放、鍵盤與螢幕閱讀器標示）；`tests/test_experience_stories_api.py` 涵蓋 API 的審核狀態、匿名遮蔽與不回傳作者識別。

`tests/e2e/test_system_motion.py` 涵蓋 15 個導覽目的地、返回、快速切換、搜尋結果、選單、鍵盤展開收合、彈窗、學校分頁、393／834／1440 px 排版、即時減少動態偏好，以及動態程式載入失敗。搭配既有導覽、地圖、收藏及圖示回歸測試。

本次僅套用於 Web 使用者介面。內部資料審查頁與原生 App 不在這次修改範圍。
