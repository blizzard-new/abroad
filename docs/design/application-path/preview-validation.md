## 本輪發現並修正

- 章節間補連續路徑，並讓每相鄰關卡左右換向。
- 切換計畫時清除上一份地圖位置，避免定位到錯誤關卡。
- 外部通知各有紀錄進度條，但不加入個人分母；修正通知章節的計數。
- 手機主要操作原被卡片 overflow 隔開，改為 clip 讓底部 sticky 生效。
- 手機保留起點按鈕及網站導覽，選單觸控高度至少 44px。
- 移除任務側欄重複的泛用引導文字，只留必要提醒與來源。
- 修正心得節點應連到返國階段來源。
- 粒子使用 transform / opacity，避免每幀改變位置佈局屬性。

- `node --check`：preview.js、levels.js、source-data.js。
- Python AST 語法檢查：serve-preview.py、export-preview-sources.py。

- 根前端無設定獨立 lint/typecheck/build；本輪未修改需要 build 的隔離 bundle，未新增框架或依賴。
- 正式 owner、revision、帳號切換、草稿學期隔離、伺服器保存與文件操作仍需後續實作及驗收。預覽 localStorage 不代表正式同步已完成。
