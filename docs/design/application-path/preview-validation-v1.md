## 本輪修正

- 精簡手機頁首與預覽控制，讓第一屏看得到目前關卡。
- 補上任務卡片焦點首尾循環。
- 返回關卡的可見性加入被動 scroll + requestAnimationFrame 幾何檢查，避免只靠 IntersectionObserver 時留在隱藏狀態。
- 使用既有圖示庫確實有的圖示，不新增依賴。

## 靜態檢查與限制

- `node --check`：preview.js、source-data.js。
- Python preview server / source export script 語法檢查。
- `git diff --check`：本次設計資料夾。
- 正式產品檔案無改動；沒有對正式帳號 API 發送 mutation、沒有執行 SQL migration。
- 未宣稱跨裝置同步、真實檔案工具銜接、正式多學期隔離、登入後恢復、手機實機 60fps 或整站回歸已完成。
- 根專案沒有設定根前端 lint/typecheck/build。本輪沒有改隔離 bundle，因此沒有執行其 build；既有完整測試待正式實作後執行。
