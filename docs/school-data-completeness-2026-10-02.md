# 合作校資料完整度盤點（2026-10-02）

這份盤點回答「哪些學校的哪些資料還沒補齊」，**不補任何缺口**。它由新加入的 `exchange-info audit-data-completeness` 讀取已保存的資料產生；學生在學校詳情頁的「這所學校的資料完整度」也用同一套規則。

逐校明細見 [school-data-completeness-2026-10-02.csv](school-data-completeness-2026-10-02.csv)。

## 十個檢查項

| 項目 | 「完整」的條件 |
| --- | --- |
| 申請資格與範圍 | 學院、學制與語言資格都有明確來源 |
| 申請期限 | 流程有附來源的精確期限 |
| 申請流程 | 已發布且適用年度已確認的結構化步驟 |
| 文件與表格 | 文件清單加官方表格連結 |
| 每月生活費 | 來源明列「每月生活費總額」（含幣別、非舊年度），可換算比對預算 |
| 住宿／交通／校園生活 | 有來源整理的內容，且不是「官方未公開」 |
| 城市 | 已標示所在城市 |
| 中文說明 | 生活說明皆有中文 |

狀態分四種：已有、部分、待確認、缺。資料中寫著「官方未公開」會算「缺」，因為這代表需要向學校確認，不代表可以推測。

## 這份盤點的限制

- 兩校的 116 流程都由 115 流程複製而來，只更新了校內步驟（依 116 簡章／當日官網）；合作校端的步驟沒有重新查核，仍沿用 115 的查核日期。長庚的 115 流程是已標為發布且已確認的版本，116 則是未審核，所以「已有」不代表可以上線，**以 `exchange-info audit-web-release` 為準**。
- 長庚合作校名單是即時爬取，離線盤點用已保存的 destination profile 代替，所以長庚的「申請資格」欄不列入。
- 缺口只代表**本平台目前整理到哪裡**，不代表學校沒有公開，也不代表可以用推測補上。補查仍須逐校找官方頁面；先前列出的 30 筆翻譯缺口是網站導覽列或跨校混入的文字，翻譯無法修復，需重新取得正確來源（見 [school-content-completion-2026-10-01.md](school-content-completion-2026-10-01.md)）。
- 臺北大學 116 新增的同濟大學沒有找到官方網站與生活資訊，圖片也缺，如實列為缺口。

## 預算與課程推薦如何使用這份資料

- 費用只採用來源**明確寫出的每月生活費總額**；住宿單項、學位生費用、舊年度（含「歷史基準」「底層引用 2021 年調查」）一律不用於比對。
- 換算新台幣使用 `scripts/refresh_fx_reference.py` 取得的參考匯率（2026-10-02，Exchange Rate API），畫面標示為「概估」，不是銀行牌價。
- 結果分「在預算內／可能超出／高於預算／無法比對」；**無法比對時一定寫出原因**，且不含學費、機票、簽證、保險與抵達初期費用。
- 授課語言依臺北大學名額表語組（英語／日語／中文）；其他學校只能看資格說明中提到的語言能力，並註明「不等於授課語言」。
- 課程只比對公開資料中是否提到你填的領域；沒有逐校課程目錄，因此不會宣稱可修或可抵免。
