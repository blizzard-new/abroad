## 重新產生

畫面改版後要重拍截圖；改台詞要重做旁白。三個步驟可以分開跑。

```bash
node docs/cgu-demo/video/capture.js docs/cgu-demo/video/shots
```

```bash
pip install gTTS && python3 docs/cgu-demo/video/narration.py
```

```bash
node docs/cgu-demo/video/render.js --stills 2.5,8.6,12,15.6,21.5,28.5
```

```bash
node docs/cgu-demo/video/render.js
```

- `capture.js` 會在展示站建立林小程的示範申請、完成第一項，最後按「重設我的展示資料」清掉，只影響該次瀏覽器的虛構工作區；放大與框選位置寫入 `shots/regions.json`。
- `narration.py` 讀 `narration.txt`（一行一句），產生 `out/narration.wav` 與每句起訖時間 `out/narration.json`；台詞太長、蓋過最後 1 秒會直接報錯。走 TLS 檢查代理時請設 `REQUESTS_CA_BUNDLE`。
- `render.js` 預設輸出 v2（`out/uniway-cgu-opening-30s-narrated.mp4`），標題字型從 Google Fonts 載入（有 `HTTPS_PROXY` 時走代理）。輸出 v1：`node docs/cgu-demo/video/render.js --page opening.html --silent`。
- 確認後再把 `out/` 裡的 MP4 複製到本資料夾覆蓋；`shots/` 與 `out/` 不進版控。
