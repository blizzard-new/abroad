上台第 0:00–0:30 播放的橫式影片：[`uniway-cgu-opening-30s.mp4`](uniway-cgu-opening-30s.mp4)，1920×1080、30 fps、H.264，長度剛好 30.0 秒（含淡入淡出），內含無聲音軌。

實機截圖拍攝於 2026-11-12，當時展示站部署版本為 `9481a25b`（`/health` 的 revision）。展示站改版後請重拍再輸出。

- 不配音也看得懂：每個畫面一句大標題，字級以投影可讀為準。
- 痛點段標示「情境示意」；解法段是展示站的真實截圖，標示「實機畫面｜UniWay CGU 展示站・虛構學生」。
- 不使用長庚校徽或校色，結尾註明「獨立學生專案，非長庚大學官方網站」。

## 重新產生

畫面改版後要重拍截圖，影片才會和現場一致。

```bash
node docs/cgu-demo/video/capture.js docs/cgu-demo/video/shots
```

```bash
node docs/cgu-demo/video/render.js --stills 3,9.5,16,20.5,23.5,28
```

```bash
node docs/cgu-demo/video/render.js
```

先看靜態畫面確認放大與框選位置正確（位置由 `capture.js` 量測後寫入 `shots/regions.json`），再輸出影片。

`capture.js` 會在展示站建立林小程的示範申請、完成第一項，最後按「重設我的展示資料」清掉，只影響該次瀏覽器的虛構工作區。輸出在 `out/uniway-cgu-opening-30s.mp4`，確認後再複製到本資料夾覆蓋；`shots/` 與 `out/` 不進版控。
