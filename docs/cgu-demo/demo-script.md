# 7 分鐘活動操作腳本與 3 分鐘答詢

依本分支實際完成的功能撰寫。開場影片與簡報由講者準備，本次沒有產製影片或投影片。操作段 3:30–6:40 共 190 秒；保留 6:40–7:00 結語與緩衝。

## 事前固定情境

使用一般瀏覽器（避免會自動清理儲存的模式）、一個展示分頁，縮放 100%，建議桌面 1440×900。使用審查後的展示網域；未部署前用本機網址。此時目標 `demo.uniway-tw.com` 尚未設定，請勿對評審宣稱已上線。

若已有計畫，先開「我的旅程」→「重設展示資料」→「確認重設展示資料」。回「交換探索」，清除搜尋，保持預設 Lincoln 研究目標。起始不載入計畫，首頁可直接看到六階段預覽。先確認官方連結能開啟，網路不佳時留在本站的來源摘要，不等待外站。只輸入虛構情境，不輸入真實證件或校務帳密。

## 台上流程

| 時間 | 點哪裡／操作 | 講什麼 | 評審會看到 |
| --- | --- | --- | --- |
| 0:00–0:30 | 播放講者準備的開場影片 | 一位交換學生從找資料到出發，常不知道下一步 | 影片；不宣稱產品有尚未完成的 AI |
| 0:30–1:20 | 簡報問題情境 | 規定分散、期限不同、核對資格與文件耗時；這是其中一種旅程 | 學生需求，對應問題洞察 |
| 1:20–2:20 | 簡報核心方案 | 以六階段導航＋附來源資訊＋手動待辦，把資訊變成下一步 | 方案及可實作的範圍 |
| 2:20–3:10 | 簡報價值與邊界 | 復用 UniWay 資料與品牌；獨立作品；不做假的校方串接或送件 | 可落地的現階段價值與未來合作方向 |
| 3:10–3:30 | 切到展示首頁 | 接著以虛構學生操作同一條主線 | 乾淨的 CGU 首頁與六階段預覽 |
| 3:30–3:50 | 「探索參考學校」，展開 Lincoln「申請條件與來源」 | 從長庚歷史參考資料起步，先分清當期資格與歷史資訊 | 語言、研修、歷史名額／日期、官方連結；全部有適用限制 |
| 3:50–4:15 | 向下看「申請條件」，再點「資料與來源」 | 官方校內期間與目的校時間分開。來源不一致就請確認，不自行選一個當答案 | 平均／語文／文件摘要、查核日期、Lincoln 日期差異與春季文字矛盾 |
| 4:15–4:35 | 回「交換探索」，點「載入示範計畫」 | 林小程已讀須知、整理志願；現在先確認語言及當期名額 | 六階段、2/15 進度、第一個未完成項目與「前往這個待辦」 |
| 4:35–5:00 | 「前往這個待辦」，設定個人目標日（如 2026-12-01），勾選「確認目標校語言門檻與當期名額」 | 在示範情境中假設學生已自行完成核對，手動記錄；勾選不是系統驗證或校方核准 | 進度變 3/15，下一步立即變成「確認成績單、平均與排名資料」 |
| 5:00–5:20 | 「前往這個待辦」，看校內文件，再重新整理；選「探索與選校」查看日期 | 日期是自己設定的目標，不是官方 deadline；這裡只存在這個瀏覽器 | 勾選、3/15 與個人日期仍保留，不需正式帳號 |
| 5:20–5:45 | 點「姊妹校申請」、「出發準備」、「抵達與返國」 | 後段也可操作，但具體要求依目的地／學期確認。錄取、抵免與受理由校方判定 | 每階段有實際待辦，生活建議與官方來源／待確認標示 |
| 5:45–6:10 | 「未來合作」 | 尚未串接校方：先授權資訊同步，再研究有同意的狀態同步，最後才是正式接收 API | 三階段規劃、AI 問答規劃中、授權／最小權限／加密與保存政策 |
| 6:10–6:30 | 「我的旅程」→「重設展示資料」→確認 | 下一位評審可重演；只清這份虛構展示 | 回到空計畫，正式資料不受影響 |
| 6:30–6:40 | 空狀態按「載入示範計畫」 | 同一情境可重現，學生總能找到一個可做的下一步 | 再回 2/15 的固定起點 |
| 6:40–7:00 | 結語及緩衝 | 從找資料，到知道下一步；現階段提供可靠導航，校方整合以正式授權為前提 | 保持旅程主畫面，準備答詢 |

若超時，略過後段逐項勾選，保留「一次勾選改變下一步」「重整保留」「來源與邊界」三個證據。不可為節省時間宣稱已正式送件或即時 AI。

## 常見答詢（3 分鐘）

| 問題 | 可直接回答 |
| --- | --- |
| 這和資訊網站有什麼不同？ | 不只列資料；可把來源、個人待辦與六階段串成下一步，能保存與重現。下一步以清單順序找第一個未完成項目，並非 AI 推論。 |
| AI 在哪裡？ | 目前產品 AI 停用，展示沒有即時模型。先確保來源與流程可靠；未來在校方授權下研究附來源問答，資料不足要說無法確認。 |
| 是長庚正式系統嗎？ | 不是，是獨立黑客松作品，尚未獲採用、認證或合作，也未與校方串接。 |
| 合作校及期限都核實了嗎？ | 三個官方主頁有本次讀取紀錄，但三所展示校來自歷史快照，當期名額和適用性待確認。不同日期有並列，沒有推測。 |
| 勾選申請完成會送去哪裡？ | 不送出，純手動展示紀錄；沒有校方收件、資格核准或錄取效果，也沒有私人文件上傳。 |
| 進度存在哪裡？可重設嗎？ | 只在此網域、此瀏覽器的展示專用 localStorage；可確認重設。沒有帳號、跨裝置同步或資料庫寫入；儲存失敗會明示。 |
| 流程對所有學校都相同嗎？ | 六階段是導航框架，不是統一規定。面試、體檢與後續文件按當期通知確認；非 Lincoln 計畫不套用 Lincoln 規則。 |
| 如何與校方合作？ | 先確認授權與維護責任，再以學生同意、最小權限、加密、保存及刪除政策研究官方 API。沒有 API 就不宣稱已串接。 |
| 能立即上線嗎？ | 程式、部署指令與本機證據已備妥，仍待 PR 審查、獨立服務與容量選擇、網域／HTTPS 授權及遠端驗證；相關既有回歸問題另列，不宣稱全數通過。 |
