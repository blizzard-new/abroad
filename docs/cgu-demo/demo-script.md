# 長庚專屬展示站操作腳本與答詢

本腳本對應長庚大學專屬展示站（`https://demo.uniway-tw.com` 或本機獨立預演 `http://127.0.0.1:8765`），介面以正式產品樣貌呈現，展示環境說明集中於展示工具；採用與 UniWay 主站一致的介面，母校固定為「長庚大學」（隱藏用戶評價入口、不顯示切換學校選單），合作校名冊統一為 **78 所**。登入名稱顯示為「林小程」，簡報截圖與錄影可加上 `?present=1` 參數隱藏右下角展示工具列。請勿輸入真實個資或上傳私人機密檔案。

## 上台前準備

1. 開啟長庚展示站並等待畫面完成載入。
2. 點選右下角「**展示工具**」→「**重設資料**」→「**確認重設**」，確保申請計畫、送件紀錄、詢問單、返國心得與通知鈴鐺皆回到乾淨初始狀態（國際處工作台仍保有 5 筆 `CGU-116-1-*` 預載案件）。
3. 展示期間保持同一瀏覽器與同一網域，重新整理可完整保留狀態；若需無工具列的全畫面截圖或錄影，可使用 `/?present=1`。

## 主線二：校內送件、國際處工作台與問答互動路線（核心驗收流程）

> **操作路線摘要**：
> **確認第 1 階段資格與設定 2 所志願 → 依序備齊 5 項文件（單關或預檢表單雙向同步）→ 進入「送出校內申請」關卡預檢缺件 → 補齊後送出取得編號並同步進度（6 / 23）→ 切到國際處工作台要求補件 → 切回學生端「今天」分頁看到補件原因與通知 → 提問轉承辦 → 承辦回覆**

1. **前置檢核與志願／文件連動確認**
   - 點「**我的申請**」總覽右側「**準備完成**」進度條進入「**準備清單**」，確認第 1 階段由「確定母校／出國學期／交換目標」（自動完成、不計分）→「閱讀長庚校內申請須知」→ 各項資格與當期名額檢查 →「挑選 2 所志願學校」依序排列。
   - 進入「**挑選 2 所志願學校**」關卡設定第 1／2 志願並點「**儲存並完成此關**」，切至「**時程**」分頁即可看到「我的志願」與之一致（且「時程」僅保留行事曆、我的志願與我的任務）。
   - 進入第 2 階段任一官方文件關卡（例如「**備齊：線上申請表**」`cgu-doc-online-form`），直接上傳檔案即自動標記該關完成（此時準備完成升為 `1 / 23 項`）；亦可於同一處刪除後同步取消完成。

2. **學生預檢缺件（不可送出）**
   - 在「**我的申請 → 今天**」點「**前往這一項 →**」或單行摘要「**前往送件關卡 →**」，進入關卡「**送出校內申請（12/21 17:00 截止）**」；此處才展開完整「**送交國際處**」表單（第一志願預設帶入共用志願設定或目前計畫目標校，右上僅保留「問國際處」；檔案區說明「檔案僅用於完整性檢查，不會保存內容。」，並提醒「實際申請仍須依國際處公告填線上表單並繳交紙本。」）。
   - 若先僅選擇部分測試檔上傳（學生畫面僅顯示已選取檔名與「已備齊」狀態，不暴露技術雜湊資訊），對應的 `cgu-doc-*` 關卡會即時標為已完成。
   - 按「**檢查文件齊備狀態**」：預檢區塊明確列出缺漏項目（例如尚缺「含排名的中文歷年成績單、一頁讀書計畫」），且「**送交國際處**」按鈕維持停用（API 亦拒絕缺件或無申請計畫之送出）。

3. **補齊後送出取得 `CGU-116-1-A` 收件編號與進度更新**
   - 點右下角「**展示工具**」→「**帶入示範檔**」（或逐一補齊剩餘檔案），5 項官方文件全部顯示「已備齊」。
   - 按「**送交國際處**」：成功建立送件紀錄，系統自動將 5 項 `cgu-doc-*` 官方文件關卡與 `cgu-internal-submit` 關卡皆標為已完成並更新準備完成數（`0 / 23 項` → `6 / 23 項`）；確認訊息顯示 `CGU-116-1-A...` 收件編號與「**正式申請請依國際處公告完成線上表單與紙本繳交**」及官方公告連結，下方「我的送件紀錄」呈現三階段狀態時間軸（**已送出** → 已收件 → 要求補件／初審通過）。

4. **切到國際處工作台要求補件**
   - 點右下角「**展示工具**」→「**切換國際處視角**」，進入「**國際處工作台**」。
   - 檢視上方統計列（各校志願數、缺件／要求補件數、最常被問的問題）與預載案件，並在「申請收件匣」找到剛剛送出的 `CGU-116-1-A...` 案件。
   - 在該案件的補件原因欄輸入「`歷年成績單未附班級排名百分比，請補交教務處核章版`」，點選「**要求補件**」：收件匣狀態立即更新為「要求補件」，上方缺件統計同步增加（亦可測試「確認收件」「初審通過」）。

5. **切回學生端看到通知與「今天」即時同步**
   - 點「**切回學生視角**」（或右下角「展示工具」→「切換學生視角」）：
     - 右上角／導覽列**通知鈴鐺**立即顯示未讀紅點數字，點開可見「**要求補件**」通知（標示「國際處通知」），通知行動連結直達 `cgu-internal-submit` 關卡。
     - 回到「**我的申請 → 今天**」分頁，最上方狀態列顯示收件編號與「要求補件／已收件／初審通過」狀態，「**現在做這件事**」主卡片在要求補件時會切換為補件處理事項、顯示補件原因並可直接連回送件關卡補件；下方單行摘要列與關卡內時間軸（已送出 → 已收件 → **要求補件**）於重新整理後依然保留。

6. **學生端「問國際處」：常見問題回覆與轉送承辦**
   - 點導覽列「**問國際處**」。
   - 先點常見問題「截止日與紙本規定」送出：立即顯示公告規則答案、官方公告連結與「**依國際處公告與常見問題回覆**」標籤（亦可按「仍要詢問承辦」轉專人）。
   - 輸入「接機與特殊住宿諮詢」範例或特殊問題並按「**送出問題**」：未命中現有常見問題時，系統自動建立 `CGU-116-1-Q...` 詢問單送交國際處承辦，學生端「我的詢問紀錄」顯示「待承辦回覆」。

7. **切到國際處工作台承辦回覆（並可加入 FAQ）**
   - 點「**展示工具**」→「**切換國際處視角**」，在「詢問收件匣」找到該筆 `CGU-116-1-Q...` 詢問單。
   - 輸入承辦回覆：「`林肯大學接機預約將於獲得提名與入學許可後由對方國際處寄發連結，特殊飲食可於線上住宿表單勾選。`」，點「**回覆詢問**」（亦可點「**將回覆加入 FAQ**」，之後學生再問同類問題即直接回覆）。
   - 切回學生視角回到「問國際處」：學生端詢問單狀態即時變為「**已回覆**」並顯示承辦回覆內容，通知鈴鐺亦同步收到「**承辦回覆**」通知。

## 延伸展示：返國心得四段式報告、列印匯出與合作校頁公開

1. 從第 6 階段關卡 `cgu-return-credit`（「整理成績單、課綱及返國所需資料」）點選「**前往填寫返國心得 →**」（或由頂部導覽列點「**返國心得**」），選擇合作校（例如「林肯大學 Lincoln University」，從關卡進入會自動帶入目標校，並可點「返回我的申請」回到原關卡），檢視國際處學期報告表四段（出國前準備、上課情形、日常生活、課外活動及其他），每段即時計算字數且未滿 300 字不可送出。
2. 點「**展示工具**」→「**帶入心得草稿**」、選填分享影片網址、確認勾選「**同意公開給學弟妹**」，按「**送出返國心得**」取得 `CGU-116-1-R...` 編號，並可點「**匯出列印版**」開啟排版乾淨的列印檢視頁。
3. 切換至「**國際處工作台**」→「返國心得收件匣」，對該筆 `CGU-116-1-R...` 點「**核可心得公開**」。
4. 切回學生視角並開啟「林肯大學 Lincoln University」學校詳細頁，即可在「**學長姐心得**」區塊看到剛核可公開的四段報告與影片連結。

## 評審常見答詢

- **和主站 `app.uniway-tw.com` 的關係？** 共用同一套前端元件與 78 所長庚合作校資料，但運行於獨立的長庚專屬展示環境（`demo.uniway-tw.com`），母校固定顯示長庚大學，與正式站資料庫及帳號完全隔離。
- **校方現在已經串接 API 了嗎？** 尚未。介面以正式產品樣貌呈現，展示環境說明集中於展示工具的「關於此展示」；目前後端由 `MockCguConnector` 提供完整雙向互動流程，程式已抽離 `SchoolConnector` 介面（見「展示工具 → 校方介接規格」），未來校方若提供正式 API，只需替換實作類別即可銜接。
- **檔案上傳會不會留存個資？** 不會。選檔送出後只在記憶體計算完整性檢查雜湊並記錄檔案中繼資料，檔案內容位元組當場丟棄、絕不寫入磁碟；且按下展示工具的「重設資料」即會一併清除。
- **「問國際處」有用 AI 嗎？** 沒有。完全依長庚大學國際處公告與已整理常見問題回覆（「依國際處公告與常見問題回覆」），避免模型幻覺誤導申請資格或截止時間；需專人協助的問題直接建立 `CGU-116-1-Q` 詢問單轉入國際處工作台。
