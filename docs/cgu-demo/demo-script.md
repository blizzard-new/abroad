# 長庚專屬展示站操作腳本與答詢

本腳本對應長庚大學專屬展示版（`https://demo.uniway-tw.com` 或本機獨立預演 `http://127.0.0.1:8765`），採用與 UniWay 主站一致的介面，母校固定為「長庚大學」（隱藏空白的論壇與用戶評價入口，不顯示切換學校選單），合作校名冊統一為 **78 所**。全程使用虛構學生「林小程（生物醫學工程學系 大三・多益 750）」，請勿輸入真實個資或上傳私人機密檔案。

## 上台前準備

1. 開啟長庚展示站並等待畫面完成載入。
2. 點選底部控制列「**重設我的展示資料**」→「**確認重設**」，確保申請計畫、模擬送件、詢問單、返國心得與通知鈴鐺皆回到乾淨初始狀態（國際處視角仍保有 5 筆標示清楚的虛構示範案件）。
3. 展示期間保持同一瀏覽器與同一網域，重新整理可完整保留狀態。

## 主線二：校內模擬送件、國際處視角與問答互動路線（核心驗收流程）

> **操作路線摘要**：
> **學生預檢缺件 → 補齊後送出取得編號 → 切到國際處視角要求補件 → 切回學生端看到通知 → 提問未命中轉承辦 → 承辦回覆**

1. **學生預檢缺件（不可送出）**
   - 前往「**我的申請**」，捲動至「**送交國際處（模擬）— 校內五項應備文件預檢**」（畫面固定顯示「模擬・尚未與校方串接」與「實際申請仍須依國際處公告填線上表單並繳交紙本。」）。
   - 先只為前 3 項文件按「帶入示範檔」（或選擇任意測試檔；畫面顯示檔名、大小、類型與 `SHA-256`，並註明「展示版不保存檔案內容，請勿上傳真實個資」）。
   - 按「**執行完整性預檢**」：預檢區塊明確列出缺漏項目（例如尚缺「含排名的中文歷年成績單、一頁讀書計畫」），且「**送交國際處（模擬）**」按鈕維持停用（API 亦拒絕缺件送出）。

2. **補齊後送出取得 `SIM-` 收件編號**
   - 點「**一鍵帶入全部示範測試檔**」（或逐一補齊剩餘 2 項），5 項官方文件全部顯示「已備齊（僅存雜湊）」。
   - 按「**送交國際處（模擬）**」：成功建立模擬申請，畫面顯示 `SIM-APP-...` 收件編號、送出時間與三階段狀態時間軸（**已送出** → 已收件 → 要求補件／初審通過）。

3. **切到國際處視角要求補件**
   - 點底部展示控制列「**切換為國際處視角**」，進入「國際處視角（模擬）— 承辦收件匣與統計工作台」。
   - 檢視上方統計列（各校志願數、缺件／要求補件數、最常被問的問題）與預先載入的 5 筆虛構示範資料，並在「申請收件匣」找到剛剛送出的 `SIM-APP-...` 案件。
   - 在該案件的補件原因欄輸入「`歷年成績單未附班級排名百分比，請補交教務處核章版`」，點選「**要求補件**」：收件匣狀態立即更新為「要求補件」，上方缺件統計同步增加。

4. **切回學生端看到通知與狀態更新**
   - 點底部「**切換回學生視角**」（或頁首「切回學生端查看通知與狀態」）：
     - 右上角／導覽列**通知鈴鐺**立即顯示未讀紅點數字，點開可見 `【模擬・要求補件】` 通知。
     - 「我的申請」中的 `SIM-APP-...` 案件卡片同步顯示紅色警示「國際處要求補件原因」與更新後的時間軸（已送出 → 已收件 → **要求補件**）；重新整理頁面後狀態依然保留。

5. **學生端「問國際處」：先測命中規則，再測提問未命中轉承辦**
   - 點導覽列「**問國際處**」。
   - （選配對照）先點快速測試「截止日與紙本（命中）」送出：立即顯示 `demo_data` 規則答案、官方公告連結與「**規則式比對，非 AI**」標籤（亦可按「仍要詢問承辦」轉人工）。
   - 輸入未收錄之特殊問題（或點快速測試「特殊住宿接機（未命中轉承辦）」）並按「**送出問題（先比對 FAQ）**」：系統因未命中現有規則，自動建立 `SIM-INQ-...` 詢問單送入模擬收件匣，學生端列表顯示「待承辦回覆」。

6. **切到國際處視角承辦回覆（並可加入 FAQ）**
   - 點底部「**切換為國際處視角**」，在「詢問收件匣」找到該筆 `SIM-INQ-...` 詢問單。
   - 輸入承辦回覆：「`林肯大學接機預約將於獲得提名與入學許可後由對方國際處寄發連結，特殊飲食可於線上住宿表單勾選。`」，點「**回覆詢問**」（亦可點「**將回覆加入 FAQ**」，之後學生再問同類關鍵字即會直接命中 FAQ）。
   - 點「**切換回學生視角**」回到「問國際處」：學生端詢問單狀態即時變為「**已回覆**」並顯示承辦回覆內容，通知鈴鐺亦同步收到 `【模擬・承辦回覆】` 通知。

## 延伸展示：返國心得四段式報告、列印匯出與合作校頁公開

1. 點導覽列「**返國心得**」，選擇合作校（例如「林肯大學 Lincoln University」），檢視國際處學期報告表四段（出國前準備、上課情形、日常生活、課外活動及其他），每段即時計算字數且未滿 300 字不可送出。
2. 點「**帶入虛構 300 字示範草稿**」、選填分享影片網址、確認勾選「**同意公開給學弟妹**」，按「**送出返國心得（模擬）**」取得 `SIM-RPT-...` 編號，並可點「**匯出列印版**」開啟排版乾淨的列印檢視頁。
3. 切換至「**國際處視角**」→「返國心得收件匣」，對該筆 `SIM-RPT-...` 點「**核可心得公開**」。
4. 切回學生視角並開啟「林肯大學 Lincoln University」學校詳細頁，即可在「**學長姐心得（示範資料）**」區塊看到剛核可公開的四段報告與影片連結。

## 評審常見答詢

- **和主站 `app.uniway-tw.com` 的關係？** 共用同一套前端元件與 78 所長庚合作校資料，但運行於獨立的長庚專屬展示環境（`demo.uniway-tw.com`），母校固定顯示長庚大學，與正式站資料庫及帳號完全隔離。
- **校方現在已經串接 API 了嗎？** 尚未。畫面所有互動均明確標示「模擬・尚未與校方串接」，收件編號皆以 `SIM-` 開頭。程式已抽離 `SchoolConnector` 介面（見「校方介接」規格頁），未來校方若提供正式 API，只需替換 `MockCguConnector` 類別即可銜接。
- **檔案上傳會不會留存個資？** 不會。選檔送出後只在記憶體計算 `SHA-256` 並記錄檔名、大小與類型，檔案內容位元組當場丟棄、絕不寫入磁碟；且按下「重設我的展示資料」即會連同雜湊紀錄一併清除。
- **「問國際處」有用 AI 嗎？** 沒有。完全採用 `demo_data` 內已查核規則與 FAQ 的關鍵字比對（畫面上標明「規則式比對，非 AI」），避免模型幻覺誤導申請資格或截止時間；無法命中的特殊問題直接轉入模擬承辦收件匣。
