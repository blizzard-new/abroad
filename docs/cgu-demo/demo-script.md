# 7 分鐘展示與答詢

以最後交付的原版 UniWay 介面為準；目前為獨立本機展示，目標網域尚未上線。全程使用虛構學生「林小程」，不要輸入真實成績、護照或校務帳密。

## 上台前

啟動獨立 demo service，開網站等載入完成。先走一次搜尋和載入示範申請，以確認服務已暖機；按底部「重設我的展示資料」→「確認重設」，回首頁。保持同一瀏覽器、同一網域，不在展示中重啟服務。另備官方摘要的「來源與展示說明」；外部官方網頁若斷線，指出資料查核範圍即可。

## 3 分鐘評審答詢

- **和原 UniWay 的關係？** 同一份介面與主要功能，母校固定長庚；不是另外畫一個簡化網站。展示工作區隔離，未使用正式帳號。
- **有幾所當期可申請？** 本次不能確認。目錄 77 筆是歷史混合方案參考，當期名額、方案、院系限制須依國際處公告；不把全平台學校當成長庚合作校。
- **是否真的儲存？** 是，原帳號／加密草稿服務在獨立暫存環境保存；重新整理可還原。24 小時 session 或服務重啟後可能消失；不是長期正式帳號。
- **校方有收到申請嗎？** 沒有。所有進度都是個人準備紀錄，沒有正式文件上傳、送件、受理或學分核准。
- **AI 做什麼？** 本版沒有即時 AI 問答。核心是有來源的資訊與可操作流程；日後有授權資料再研究附來源回答。
- **如何合作？** 授權公告／表格／FAQ → 學生同意下的登入與狀態同步 → 有正式接收 API 時研究送達與收件編號。需要最小權限、加密、保存／刪除政策；錄取與抵免由校方判定。
- **還缺什麼？** 當期逐校規則核對、正式合作、安全登入與長期資料治理，以及經審查授權的獨立部署。不能用 noindex 冒充保護。
