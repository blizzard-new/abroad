## 重新產生

畫面改版後要重拍截圖，影片才會和展示站一致。

```bash
node docs/cgu-demo/intro-video/capture.js docs/cgu-demo/intro-video/shots
```

```bash
node docs/cgu-demo/intro-video/render.js --stills 2.5,7.5,13,17.5,22.3,24.9,28.5
```

```bash
node docs/cgu-demo/intro-video/render.js
```

先看靜態畫面確認放大與框選位置正確（位置由 `capture.js` 量測後寫入 `shots/regions.json`），再輸出影片。配樂由 `marketing/promo-video/music.py` 的 `cgu-intro` 設定產生（需要 numpy）；加 `--silent` 則輸出無聲音軌版本。

`capture.js` 會在展示站建立林小程的示範申請、完成第一項，最後按「重設我的展示資料」清掉，只影響該次瀏覽器的虛構工作區。輸出在 `out/uniway-cgu-intro-30s.mp4`，確認後再複製到本資料夾覆蓋；`shots/` 與 `out/` 不進版控。
