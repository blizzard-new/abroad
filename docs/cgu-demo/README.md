# UniWay CGU｜長庚大學專屬展示版（demo.uniway-tw.com）

這個版本直接共用 UniWay 的 `static/index.html`、首頁、導覽、學校搜尋、收藏比較、日曆、文件工作台及「我的申請」元件；長庚大學為固定母校，保留預載長庚交換文章與提問的「論壇」入口、隱藏「用戶評價」入口，並將「切換就讀學校」改為固定顯示「長庚大學」。另提供 `SchoolConnector` 抽象校方介接層與 `MockCguConnector` 後端實作、可收合的底部「展示工具」、來源說明與每位訪客獨立的瀏覽器工作區。介面以正式產品樣貌呈現，展示環境說明集中於展示工具；未修改 `pyproject.toml` 或 `uv.lock`，一般 `create_app()` 行為與正式主站完全不變，沒有新增資料庫、付費服務、AI 模型呼叫或外部網路連線。

## 實際範圍

| --- | --- |

| 獎學金專頁（頂部導覽新增「獎學金」） | 將首頁原有之補助卡片完整移至 `#scholarships` 專頁（首頁不放任何獎學金資訊），以統一結構化卡片呈現長庚全數四項出國補助要點：**領航者補助（2B00004）**、**教育部學海惜珠（2B00005）**、**境外短期學分課程（2B00010）**、**學海築夢及新南向學海築夢（2B00006）**，附分類篩選與資格提示 |
| 收藏與比較 | 使用原有 UI、workspace 與隔離的瀏覽器偏好 |
| 我的申請與官方期限 | 頂部導覽為五個分頁（**今天／計畫／準備清單／我的任務／時程**），總覽「**準備完成**」進度條可直接點擊開啟 23 項「準備清單」；從「今天／計畫／時程／路徑地圖」開啟關卡或子檢視時，左上角依實際來源顯示「**回到今天／回到計畫／回到時程／回到路徑地圖**」（直接開啟網址預設「回到準備清單」）。第 1 階段「探索與選校」將計畫設定（母校／出國學期／交換目標，建立後自動完成且不計入 23 項配分）置於最前，接著閱讀須知、8 項申請資格與當期名額檢查，最後才是「挑選 2 所志願學校」並刪除重複的語言門檻重複項；第 2 階段「校內申請」將校內 5 項官方文件拆為獨立關卡，與預檢上傳雙向同步。**時程**分頁僅保留官方與個人行事曆、我的志願及我的任務，不再混入找學校與申請入口；「挑選 2 所志願學校」、時程「我的志願」與送件表單志願共用同一組持久化志願設定。**下一個已確認的官方期限**與「官方期限」專頁統一以 `Asia/Taipei` 顯示 **116-1 校內申請截止 2026/12/21 17:00（臺灣時間）** 並附國際處公告來源（跨時區瀏覽不偏移） |
| 送交國際處 | 位於「我的申請」與關卡流程整合：無申請計畫時不顯示；「今天／計畫／準備清單／我的任務／時程／地圖」與其他關卡僅顯示單行「校內送件」狀態摘要列，完整表單僅於「送出校內申請（12/21 17:00 截止）」關卡（`cgu-internal-submit`）展開，且第一志願預設帶入共用志願設定（或目前計畫目標校）、右上僅保留「問國際處」。依官方 5 項文件（線上申請表、家長同意書、語文證明、含排名的中文歷年成績單、一頁讀書計畫）做完整性預檢並雙向同步對應 5 項 `cgu-doc-*` 文件關卡；送出後自動標記 `cgu-internal-submit` 與 5 項文件關卡完成並更新進度，產生 `CGU-116-1-A0001` 格式收件編號與狀態時間軸，確認畫面保留「正式申請請依國際處公告完成線上表單與紙本繳交」及官方公告連結；後端於無申請計畫時拒絕送件（`422 missing_application_plan`） |
| 國際處狀態回寫「今天」 | 國際處工作台執行確認收件、要求補件或初審通過後，學生端「今天」分頁上方顯示目前送件狀態列；「要求補件」時，「現在做這件事」改為補件處理事項與原因並附前往送件關卡連結 |
| 檔案完整性預檢（無內容寫入） | 選檔後於記憶體計算 `SHA-256` 即丟棄原始位元組，磁碟不保存檔案內容；上傳或清除預檢檔時同步更新對應 5 項 `cgu-doc-*` 關卡進度（亦可從單一文件關卡直接補件或刪除）；學生畫面僅顯示已選取檔名與中性說明「檔案僅用於完整性檢查，不會保存內容。」 |
| 問國際處 | 先依 `demo_data/content.json` 與工作區收錄之規則與常見問題回覆（顯示「依國際處公告與常見問題回覆」與官方來源連結）；未命中或點選「仍要詢問承辦」時建立 `CGU-116-1-Q0001` 格式詢問單送交國際處工作台 |
| 返國心得 | 第 6 階段關卡 `cgu-return-credit` 內嵌專屬橋接卡「**前往填寫返國心得 →**」，可直接導向 `#return-report`（自動帶入該計畫合作校，並於「返回我的申請」返回原關卡）；依國際處學期報告表四段（出國前準備、上課情形、日常生活、課外活動及其他），每段即時顯示字數並要求至少 300 字；可填影片網址（不上傳影片）與勾選「同意公開給學弟妹」。送出後取得 `CGU-116-1-R0001` 格式編號並可匯出列印版，經承辦核可且同意公開者顯示於該合作校詳細頁「學長姐心得」 |
| 校方介接規格 | 自學生導覽列移出，改由底部「展示工具 → 校方介接規格」進入（供校方資訊單位檢視），列出 `SchoolConnector` 四個標準方法（`submit_application`、`send_inquiry`、`submit_return_report`、`get_status`）之用途、送出／回傳欄位、需校方提供項目與目前狀態（`MockCguConnector`），並說明三階段合作（不需校方配合／小型試辦／需校方資訊單位） |
| 國際處工作台 | 由底部「展示工具 → 切換國際處視角」開啟，包含申請、詢問、返國心得三個收件匣與統計列（各校志願數、缺件數、最常被問的問題），預載 5 筆 `CGU-116-1-*` 起始案件；承辦執行確認收件、要求補件、回覆詢問、加入 FAQ、核可心得公開皆即時反映至學生端狀態與通知鈴鐺 |
| 我的任務／日曆／文件 | **我的任務**（`view=workspace`）與 23 項清單統一採用**六階段**（探索與選校、校內申請、面試與放榜、姊妹校申請、出發準備、抵達與返國），後端自動相容轉換舊制 `nomination`／`arrival`／`abroad`；個人自訂待辦以 `workspace.tasks` 為單一資料來源，在「**今天／我的任務／時程**」任一處新增或勾選完成皆雙向即時同步（並移除「今天／時程」底部重複摘要卡）；保留筆記、個人目標日期、通知文字整理與 `.ics` 匯出，停用私人檔案庫上傳、附件解析與外部日曆同步 |
| 論壇／用戶評價 | 預載長庚大學交換經驗與提問討論文章（僅供瀏覽），隱藏「用戶評價」入口，不匯入正式用戶資料 |

六階段為探索與選校、校內申請、面試與放榜、姊妹校申請、出發準備、抵達與返國（其中 3 項計畫設定關卡為不計分自動完成）。未來若與校方資訊單位對接真實 API，只需替換 `SchoolConnector` 實作類別，無須重寫前端流程。

## 本機預演與重設

```sh
PATH="$PWD/.venv/bin:$PATH" PORT=8765 sh scripts/run_cgu_demo.sh
```

開啟 `http://127.0.0.1:8765/`（若網址加上 `?present=1` 會完整隱藏底部展示工具列，方便簡報截圖與錄影）。右下角可收合的「**展示工具**」按鈕預設收合，展開後可使用：

- **切換國際處視角／切換學生視角**：在同一瀏覽器切換「我的申請」與「國際處工作台」。
- **載入示範申請**：為帳號「林小程」建立或開啟 2027 秋季（116-1）申請計畫。
- **帶入示範檔／帶入心得草稿**：一鍵填入 5 份預檢檔案或 4 段各滿 300 字的返國心得草稿。
- **校方介接規格**：開啟專為校方資訊單位設計的 `SchoolConnector` 介面規格與合作分期頁。
- **重設資料**：需確認，一併清除目前瀏覽器的申請計畫、送件紀錄、詢問單、自訂 FAQ、返國心得、承辦操作紀錄與通知。
- **關於此展示**：全站唯一保留展示環境說明之處（「這是 UniWay 為長庚大學製作的展示環境，資料不會送達長庚大學國際事務處。正式申請請依國際處公告辦理。」並附官方公告連結與資料來源清單）。

展示 Cookie 有效 24 小時；**重新整理可保留，服務重啟或 Cookie 過期會清除工作區**。請勿輸入真實個資。

獨立啟動指令：

```sh
uvicorn exchange_info.cgu_demo:create_demo_app --factory --host 127.0.0.1 --port 8765 --workers 1 --no-proxy-headers
```

## 隔離方式

- demo factory 必須在**獨立 process** 啟動；若已匯入正常 API 或帶 production／Supabase／OAuth／SMTP／OpenAI credentials，拒絕啟動。先清除 `EXCHANGE_*`，建立自有暫存目錄，再初始化共用 API；不讀取或掛載正式 data directory。
- 每個瀏覽器一個沒有 email、密碼或校方驗證狀態的隔離帳號。重用原有 JSONL 帳號、加密草稿與暫存目錄內的 `cgu_connector` 工作區；非新增資料庫。每個服務進程最多 500 個帳號，滿時回 503。
- 使用 `uniway_cgu_demo_session` 的 HTTPOnly、SameSite Strict、host-only Cookie。剝除外來 Cookie、Authorization、匿名 token，只將展示 token 交給內層 API；不接收或設定正式 session cookie。
- `localStorage` 及 `sessionStorage` 都使用 `uniway-cgu-platform:` namespace。重設只刪除此 namespace 與該帳號／`MockCguConnector` 工作區；不對全站原始 storage 呼叫清空。
- 寫入採允許清單、同 Origin 驗證、256 KB 內容大小上限；送件選檔以記憶體 `BytesParser` 解析並計算 SHA-256 後立即捨棄原始位元組，絕不寫入磁碟，學生畫面僅顯示 neutral 說明文字與檔名。私人檔案庫上傳、OAuth、驗證信、正式送件、社群發布、AI 呼叫及外部日曆同步一律回 403。
- 長庚 catalogue 只讀取已驗證雜湊的 bundled snapshot（78 所合作校），停用背景網路更新，不對任何長庚或外部系統發出網路請求，亦不使用長庚校徽或宣稱校方背書。
- 回應有 `noindex` 與原有 CSP（禁止 inline script 與 inline event attributes）；動態資料 `no-store`，公開靜態資產可快取一小時。

## Windows 獨立展示站（demo.uniway-tw.com）

長庚展示站以獨立 checkout、獨立 Docker Compose 專案（`uniway-cgu-demo`）與專用 image 運行於 Windows 主機 loopback 埠，經 Caddy 反向代理提供 `https://demo.uniway-tw.com`，與正式主站 `https://app.uniway-tw.com` 完全隔離。完整維運與手動更新步驟見 [Windows 操作指南](windows-deployment.md)：

- `start-windows.ps1` 建置固定 commit 的 image，只啟動展示容器，並驗證隔離、保存與重設；沒有自動 Git 更新，未經明確手動執行不會變更線上服務。
- `publish-windows.ps1` 預設只產生與驗證 Caddy 候選設定；明確加 `-Apply` 才套用。
- HTTPS 設定 `CGU_DEMO_PUBLIC_ORIGIN=https://demo.uniway-tw.com`；代理保留 Host，uvicorn 維持 `--no-proxy-headers`。寫入驗證固定 HTTPS Origin 與 Host，Cookie 強制 Secure，不信任客戶端 forwarded headers。
- `/health` 提供 `mode=cgu-demo`、`ui=shared-uniway-platform` 及 image revision。
