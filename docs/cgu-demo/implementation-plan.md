# 長庚專屬平台實作決策

目標是「同一套 UniWay UI/UX，專為長庚大學打造獨立展示網站（`demo.uniway-tw.com`）」，在不更動一般 `create_app()` 與正式主站行為的前提下，完整呈現長庚選校資訊與校方介接模擬流程。

| 盤點項目 | 實作與隔離設計 |
| --- | --- |
| 首頁、搜尋、地球、詳細頁、收藏比較 | 直接共用 `index.html`、`app.js`、`platform-home.js`、`metro.css`；母校固定顯示「長庚大學」（移除「切換就讀學校」互動與下拉提示），並隱藏空白的「論壇」與「用戶評價」入口 |
| 長庚合作校與期限口徑 | 離線讀取雜湊驗證之 bundled snapshot，與 `content.json` 統一為 **78 所合作校**（66 所交換、14 所雙學位，含 2 所管理學院院級參考合作校）；「我的申請」下一個已確認官方期限固定顯示 **116-1 校內申請截止 2026/12/21 17:00** 並附公告來源 |
| 校方介接層（`SchoolConnector`） | 於 `cgu_demo.py` 定義抽象介面 `SchoolConnector`（`submit_application`、`send_inquiry`、`submit_return_report`、`get_status`），並以 `MockCguConnector` 將狀態保存在各瀏覽器專屬暫存工作區；日後銜接真實校方 API 只需替換連接器類別 |
| 校方介接規格頁 | 導覽列新增「校方介接」，以表格呈現四個接口之用途、送出／回傳欄位、需校方配合事項與目前狀態（一律為「模擬」），並列出三階段合作模式（不需校方配合／小型試辦／需校方資訊單位） |
| 學生端「送交國際處（模擬）」 | 整合於「我的申請」，針對官方 5 項文件進行完整性預檢（缺件列出缺項並禁止送出）；檔案上傳以純記憶體計算 `SHA-256` 後即丟棄內容，磁碟只存檔名、大小、類型與雜湊；送出後產生 `SIM-` 編號與狀態時間軸 |
| 學生端「問國際處」 | 關鍵字比對 `demo_data/content.json` 與工作區 FAQ，標示「規則式比對，非 AI」並附官方來源連結；未命中或點選「仍要詢問承辦」建立 `SIM-` 詢問單 |
| 學生端「返國心得」 | 依國際處學期報告表四段設計，每段即時統計字數並強制至少 300 字，支援選填影片網址、列印版匯出與公開授權勾選；經模擬承辦核可且學生同意公開者，自動呈現在對應合作校詳細頁「學長姐心得（示範資料）」 |
| 國際處視角（模擬） | 底部展示列切換開啟申請、詢問、返國心得三個收件匣與統計列，預載 5 筆明確標示之虛構資料；承辦各項操作即時反映至學生端狀態與通知鈴鐺，「重設我的展示資料」一併清除所有新增狀態 |

驗證涵蓋原介面資產順序、資料隔離、缺件攔截、記憶體雜湊不落盤、零外部網路請求、承辦與學生雙向同步、重新整理狀態保留、重設完整清除與響應式瀏覽器端對端測試。
