## 預定主線

1. 展示首頁：品牌、獨立作品聲明、交換資訊與官方來源。
2. 選校與條件：少量舊快照參考、不顯示「本期可申請」結論；2027 秋季示範、目的地待確認。
3. 建立虛構學生計畫：六階段手動待辦；第一個未完成任務為下一步；不推定錄取。
4. 個人目標日期與官方期限分開；更新、切換、重整保存；可取消的展示專用重設。
5. 無資料／失效來源／儲存受限均明確處理；來源內容隨版打包以支援現場網路中斷。
6. 官方尚未串接、AI 未來規劃、合作授權與隱私邊界。
