Summary

新版把兩個入口合成一個工作臺，預設畫面只回答「現在做哪一件事」。建立計畫縮成三個問題；每個完成動作都能撤銷；斷線與續接說清楚內容在哪裡。檢查現況後，主要落差在清單過長（FAIL）、導覽圖示沒有文字（FAIL）、原始錯誤訊息（FAIL）與年份輸入（FAIL）。畫面見 設計稿，問題編號見 報告。

Flow: 第一次使用 → 第一個任務

Pattern source: flow-onboarding、flow-empty-states、flow-forms · Entry point: 側欄「我的申請」（已登入、已選就讀學校）

Steps

  1. 1空白狀態（第一次使用）

    標題「先選一所你想去的學校」，下方預覽選好之後會看到的三件事：現在做這件事、已確認的官方期限、文件備齊度。預覽項目是範例樣式，不可點。

    Primary action: 選擇交換學校 → 就地開啟學校選擇（不換頁）

    若學生已有目標 → 「我已經有目標學校」直接進入步驟 2 並略過推薦
  2. 2新增申請計畫（3 個問題）

    目標學校（可搜尋）、預計出發學期（最近 4 個學期＋還沒決定）、學院／學系（從選校條件帶入，可修改）。系統換算並顯示對應的民國學年度。

    Primary action: 建立計畫 → 今天

    若年份組合不合理 → 欄位旁說明並不送出（後端同樣驗證）
  3. 3今天：現在做這件事

    一張深藍卡片：任務名稱、為什麼是這件、預估時間、來源。其餘資訊（期限、階段、待辦）在下方，不搶焦點。

    Primary action: 開始 → 任務面板

  4. 4任務面板

    說明、依據、輸入；自動儲存狀態；條件不符時只顯示「補填」，不顯示「確認」。

    Primary action: 完成這項 → 回到今天，顯示進度變化與「撤銷」

    若資料不足或條件不符 → 補填學院／學系、或前往官方公告

Flow: 每日使用（工作臺）

Pattern source: flow-navigation · Entry point: 側欄「我的申請」；舊網址 #my-application、#overview 都導到這裡

Steps

  1. 1打開「我的申請 · 今天」

    看到現在做這件事、下一個已確認的官方期限、階段進度、今天與本週的待辦。計畫選單、儲存狀態、⋯ 選單在頁首一列。

    Primary action: 開始 → 任務面板

    若沒有已確認期限 → 卡片說明「尚未公布」，提供「查看官方公告」與「我查到了」
  2. 2處理待辦

    勾選完成（保留 6 秒撤銷）；底部輸入框就地新增待辦；篩選：全部／某校／文件／我加的。

    Primary action: 加入 → 待辦出現在清單，不離開頁面

  3. 3切換檢視

    「計畫」並排比較多份計畫；「時程」看期限與每週時間。檢視切換是區段控制，網址記得目前檢視。

    Primary action: 計畫／時程 → 對應檢視，可用瀏覽器上一頁回來

Flow: 中途離開、斷線與復原

Pattern source: flow-errors、flow-forms（儲存與續接） · Entry point: 任何輸入中的任務

Steps

  1. 1輸入中

    自動儲存；狀態文字固定在輸入框旁：「已自動儲存・10:42」。

    Primary action: 繼續輸入 → 0.9 秒後自動儲存

  2. 2斷線

    頁面上方出現黃色橫幅：「目前離線。你寫的內容還留在這個分頁，連線後會自動儲存。請先不要關閉分頁。」顯示下一次重試倒數與「立即重試」。

    Primary action: 立即重試 → 成功後橫幅換成「已儲存」，之後消失

    若關閉分頁 → 瀏覽器離開警告；內容會遺失（待產品決定是否改存本機，UX-19）
  3. 3回來續接

    「今天」顯示「接著做：寫一段申請動機（草稿・2 小時前）」。登入過期時，原帳號重新登入後回到原內容（沿用現有機制）。

    Primary action: 接著做 → 任務面板

  4. 4誤操作後復原

    勾選完成、封存計畫都在提示條提供「撤銷／復原」，取代瀏覽器確認視窗。

    Primary action: 撤銷 → 進度與狀態還原
