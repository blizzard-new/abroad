## 2026-11-17：流程精簡（總覽合併、申請資格合併）

| 項目 | 之前 | 現在 |
| --- | --- | --- |
| 分頁 | 今天／計畫／準備清單／我的任務／時程（5 個，內容重複） | 總覽／時程／我的待辦；「計畫比較」只在有兩份以上計畫時出現 |
| 總覽 | 「今天」與「準備清單」各有一個「下一步」與期限卡，另有階段條、接下來 5 項、資格統計、快速待辦 | 一個「現在做這件事」、一個期限、整份清單 |
| 資格檢查 | 每條規則一關（長庚示範 6 關），「符合」也要按「確認內容」，缺資料時每關各填各存 | 一關「申請資格」：全部規則與結果在同一張表，缺的資料一次填、一次存，最後一次確認 |
| 清單列數（長庚示範） | 26 列、計 21 項 | 16 列、計 16 項（計畫設定三列不再列出） |
| 完成一關 | 先到「已完成」畫面，再按「下一項準備」 | 直接回總覽，提示條可「撤銷」 |
| 送件關 | 勾選「我已自行送件」再按「記錄我已送件」 | 一個按鈕「我已送件」 |
| 文件／事項關 | 必須先寫備註才能標記完成 | 備註選填 |
| 需要確認的事項 | 收合，要點開 | 直接顯示 |
| 時程 | 上方四格統計（任務數與標頭不一致）、右側再列一次期限 | 移除，期限只在最上方一處 |
| 我的待辦（空的時候） | 計數列、三個篩選、兩個匯出按鈕 | 只留「新增待辦」與起始提示 |

後端：`application_path.py` 的非確認類關卡改為「標記完成即完成」，不再要求先留文字；`check-*` 關卡與 API 不變，合併只在前端 `levels()` 與 `mapStages()`。

已確認的設計決策：
- 個人待辦統一由「時程」或「我的待辦」新增與管理，「總覽」維持單純的下一步、期限與準備清單，不放快速新增待辦框。
- 「申請資格」若有尚未取得的成績（例如尚未考語檢），儲存已填條件後此關維持未完成（不計入完成數），但「現在做這件事」往後推進，不卡住後續準備。
