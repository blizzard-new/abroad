How
                                    to Apply
Step1. Online
                                        Nomination (by Exchange Coordinator)
(1) Submit a request for a user code for the online application system via
Forms
.
(2) Receive an email with user code and CoE Web Application System information (this may take a few days).
(3) Log in to the
online application
                                        system for coordinators
and register coordinator information.
(4) Enter student information in the system and complete the nomination process.
(5) Once the submitted information is reviewed and approved, you will receive an email, and you can invite the student to the application system.
Required Information for
                                Online Nomination (For Exchange
                                Coordinator)
Step2. Online
                                Application (by Student)
(1) Once you have been nominated by the coordinator, you will receive an email containing the following information:
- Application ID
- Password for the Online Application System (for students)
- URL and password for the CoE Web Application System
(2) Log in to both the
Online Application System (for students)
and the CoE Web Application System, complete the required information, and upload all necessary documents.
(3) After you have completed and submitted the CoE Application Form, a Receipt Number will be issued. Please enter the Receipt Number in the Online Application System (for students) and submit your application to complete the online application process.
