Good to know
The courses are only available for students at Uppsala University.
If you have prior knowledge of Swedish, but haven't taken a Basic Swedish course before at UU, we recommend you to take the diagnostic test. This way, you can get placed in one of the higher levels directly.
If you have passed a course (Swedish for Academics or Basic Swedish) at the Department of Scandinavian Languages before, you don't need to write the diagnostic test to apply for the next level.
If you participate in a Basic Swedish course this semester, you should apply directly. Do not wait for the exam results to apply for the next semester.
If you are a beginner in Swedish, you do not need to write the diagnostic test. Apply to Basic Swedish 1.
The selection is done on a first come, first served basis.
If accepted to the course, we will register you in Ladok. Self-registration will not be possible.
