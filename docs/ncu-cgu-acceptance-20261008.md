# 中央對照長庚的逐項驗收表（2026/10/8，尚未完成驗收）

本表依使用者要求，以長庚實際支援的選校、母校甄選、提名後外校申請、行前與返國流程、文件中心及生活頁為範圍。資料下載量、合作校數、文字量不能代替內容驗收。中央目前的接入可供審閱，但外校當期內容仍未達完整標準；所有流程維持未發布。

## 實際比較基準

已讀共享 `models.py` 的 `PartnerUniversity`、`DestinationProfile`、`UniversityApplicationWorkflow`、`ApplicationStep`、`ApplicationDocumentRequirement`、文件模板模型；`university_registry.py`、`storage.py` 的校別及合併規則；`api.py` 的學生 dashboard、外校詳情、個人計畫、文件中心、流程與生活接口；`static/app.js` 的卡片、詳情、來源、流程及官方生活指南。

長庚基準來自 [application_documents.py](../src/exchange_info/application_documents.py)、[長庚流程](../src/exchange_info/official_data/cgu/application_workflows.jsonl)、[長庚生活資料](../src/exchange_info/official_data/cgu/destination_profiles.jsonl) 與 [school-data-completeness](school-data-completeness-2026-10-02.md)。例如116 Lincoln流程包含母校文件、母校提名、三項host文件、Offer／課程採認、簽證財力／保險／住房、母校行前行政與返國採認。

長庚既有部分資料仍有年度缺口。例如舊上海交通資料標 `verified`，同時註明未完成年度確認，並保留2025截止。本表只以其涵蓋範圍為基準；中央不複製該標籤或舊年度。中央不是因長庚欄位有文字就將同名欄位標為已核實。
