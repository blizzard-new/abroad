## 本輪已作的實質改動

- 增加可用時間、工作時數、剩餘工時、前置任務、最早開始日、等待原因與對應文件。
- 排程僅為預覽，使用明確輸入；完成任務不重新建立工作，缺工時不從準備天數猜測。
- 提示不存在的前置任務、循環依賴、等待、期限已過、容量不足和超出預覽期間。
- 帳號工作區保存時間設定與任務資訊；未提供新設定的舊客戶端不清除既有時間設定。
- 我的申請加入準備工作台，呈現今日工作、等待項目、逐日安排；設定與任務編輯收合顯示。
- 任務可選擇對應文件，開啟後定位第一個必填缺口。私人文件未因這項改動自動上傳。

本紀錄會隨驗證及後續實作更新；目標目前保持進行中。
