# 學生的送校前文件準備實測

測試使用本機平台、隔離帳號及人工製作的測試 PDF。兩位測試學生從學校搜尋收藏目標、閱讀「申請方式」，再按「開始準備」建立 2027 秋季計畫。文件分別上傳至「我的申請」對應關卡。回讀帳號後，逐一核對六個關卡的文件版本與個人備妥狀態，並各下載一份文件比對原始位元組。在校方送件關卡停下，兩案的學生送件紀錄皆為空白。

| 母校與目標 | 已驗證的文件操作 | 校方接手處 |
|---|---|---|
| 長庚大學 → Lincoln University | 116-1 的簽名申請表、家長同意書、成績單、在學證明、語言證明、讀書計畫共六個關卡。另從關卡開啟填表工具，填妥必填欄位、核對並下載平台產生的 7,344 位元組 PDF。 | 「在長庚期限內送出校內申請」提供校方公告。由學生依校方指示完成正式表單與文件上傳。[長庚公告](https://www.cgu.edu.tw/oia-ch/Subject/Detail/85785?nodeId=15817) |
| 國立臺北大學 → 關西學院大學 | 上傳六個關卡的測試檔。校內準備階段有語言成績、歷年成績單與排名兩項，校內申請階段另列簽名申請表、語言證明、研修計畫、正式成績單與排名四項。兩階段有重複的文件種類。 | 「完成臺北大學線上申請與文件上傳」顯示校方公告與「我已送件」按鈕。核對時未按下該按鈕。[臺北大學公告](https://new.ntpu.edu.tw/oia/news/6ab396bf7085cb4f0c81831f) |

測試資料可驗證檔案傳輸、保存與下載。入學資格、文件簽章、真實成績或校方受理需由學生及承辦單位確認。這兩案在診斷與修正後接續操作，無法用合計時間估算一般學生的準備工時。

## 當期沒有逐項清單時

2027 秋季的初次掃描有 32 個母校與目標組合缺少可上傳的文件關卡。使用同批學校的實際目錄與申請規則再驗證，31 組從參考年度的具名文件產生可選關卡，學生需核對當期公告後自行選擇適用。陽明交大赴南洋理工大學的 116 台聯大計畫則帶出本期九項文件或文件組，含有免繳條件的英檢及選附資料。若目標沒有可追溯的具名文件，畫面會提供聯絡單位與個人清單。逐列結果含母校、目標、文件關卡數、依據、範例與來源。[32 組文件關卡清冊](file-levels.csv)

另用 Chromium 測試臺北城市科技大學赴城西國際大學，以及陽明交大赴南洋理工大學的文件頁。城市科大頁面顯示 115 學年度來源，初始未計入準備進度，測試帳號選擇適用後才加入。陽明交大頁面顯示 116 台聯大簽名申請表。兩案均以真實上傳操作取得 HTTP 201、保存關卡、重新開啟，並下載與原檔逐位元組相同的 PDF。測試也重現「檔案已上傳、關卡尚未連結」時就按備妥會遺失連結的情形。修正後按鈕會等文件版本保存完成才恢復操作。[城市科大關卡畫面](screenshots/student-tpcu-document.png) · [陽明交大關卡畫面](screenshots/student-nycu-document.png)

校方接手方式也有差異。臺師大的 116 學年度關卡要求在校方系統選填志願並上傳六項電子備審及繳費證明。臺中科大與虎科大的參考年度關卡則分別列明「送達國際事務處或學院初審」與「送達國際事務處」，學生須再確認預計申請年度的收件方式。

金門赴三重大學的參考流程要求學生取得四個單位的審查流程表核章，再將申請表件送交國際暨兩岸事務處。個人計畫原先因表名含「審查」，把這一步顯示為等候通知，最早的送件按鈕落在面試後的錄取確認書。修正後以原流程的執行者、校內申請階段及實際交件動作辨認送件。相同條件也核對了中山、中興、政大、北商、北藝的當期流程，以及暨南、南藝的參考流程。各校開放的日期與學生能否送件仍依所選梯次查核。
