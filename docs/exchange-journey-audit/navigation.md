# 學生導覽與期別實測

採用 Chromium 的 1440 × 900 桌面及 390 × 844 手機視窗，以本機測試帳號選擇長庚大學。畫面使用真實 API 與選校資料。公開文章使用主導覽的「交換指南」入口。

| 畫面 | 操作 | 結果 |
| --- | --- | --- |
| 學校搜尋、收藏與比較 | 開啟卡片清單，從兩張卡片勾選學校，進入「並排比較」 | 兩種視窗都能展開及收起個人條件，顯示兩張收藏卡及含林肯大學的比較結果。 |
| 申請日曆 | 從 11 月往下一個月，再按「今天」 | 兩種視窗都切換到 12 月並正確回到當月。 |
| 交換預算 | 選林肯大學，設定 4 個月、每月住宿 10,000 元與膳食 2,000 元，另填一次性支出 12,000 元 | 兩種視窗都算出新臺幣 60,000 元。 |
| 論壇、個人資料 | 經主導覽進論壇，切到公共板。再由帳號按鈕查看個人資料 | 兩種視窗均能切換看板、看到自己的就讀學校。 |
| 資格與志願 | 選擇 116 學年度與「秋季／全學年梯次」 | 兩種視窗均可選擇當期已收錄的梯次。 |
| 申請文件與檢查 | 在申請文件的目標學校選單挑選林肯，按「檢查已寫文件」 | 兩種視窗皆能從目標學校選單進入文件檢查，顯示 PDF、DOCX、TXT 與 10 MB 限制。實際上傳與備件結果另見[文件旅程](document-journeys.md)。 |
| 文件清單、期限、補助 | 開啟對應工具網址，確認頁首與資料區 | 兩種視窗皆呈現文件重點整理、校內梯次與申請時程、補助資訊。 |
| 交換指南 | 主導覽 → 公開指南 → 文章 | 兩種視窗皆可開啟指南索引與文章。手機第一次在索引點入文章時超過 12 秒的測試等待時間，重開同一索引後成功讀到文章標題，寬度未溢出。 |

測試時曾中斷本機服務以重啟更新；網頁顯示含重試按鈕的錯誤提示。修正提示位置後，桌面仍能直接點選原本被遮住的卡片檢視控制。既有的 `#guide` 書籤仍可開啟站內申請指南，桌面以鍵盤啟動主導覽也能開啟論壇。

## 長庚合作校的期別

每間合作校以計畫產生的期別名稱和校方資料使用的名稱各查一次，比對選中的流程及步驟。78 間合作校 × 5 種期別，共完成 390 組比對。

| 計畫選擇 | 有對應官方步驟的合作校 |
| --- | ---: |
| 115-1 秋季 | 77 / 78 |
| 115-2 春季 | 77 / 78 |
| 116-1 秋季 | 78 / 78 |
| 116-1 秋季、全學年 | 78 / 78 |
| 116-2 春季 | 0 / 78 |
