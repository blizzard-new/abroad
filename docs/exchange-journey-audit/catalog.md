# 逐校名單與內容盤點

對登錄的 71 所母校使用 Web 同一組名單讀取器，逐一核對 10,965 筆「母校 × 合作校／方案」。每筆都有名單來源和可配對的生活檔案。依公開指南狀態，7,349 筆標記官方已核實、3,542 筆為部分核實、71 筆尚未收錄、2 筆待確認、1 筆未找到接待校生活指南。後三類仍可有母校資料或機構識別來源。10,633 筆有個別合作校流程版本。剩下 332 筆是中正名單標記未開放的 49 筆，以及淡江僅供協議／歷史參考的 283 筆。個別流程的存在不能證明本期開放或文件已獲接待校認可。

## 仍須核對的欄位

## 重跑

在專案的 Python 環境，以固定臺北時間執行下列指令。長庚採已校驗的兩份官方表單存檔，淡江及中央的時間條件按指定時點讀取。欄位盤點使用版本庫中的官方資料與公開讀取器，不會讀使用者私人文件。

```sh
python scripts/audit_exchange_catalog.py /tmp/exchange-catalog --reference-time 2026-11-18T23:57:28+08:00
```

`catalog.csv.gz` 的 `empty_fields` 是沒有值的欄位，`empty_field_evidence` 提供該校資料記下的狀態、原因或需要回查的項目。`fields_with_uncertainty_text` 是關鍵字篩選，無法涵蓋所有保留條件。`max_documents_in_one_version` 統計單一流程版本的文件名稱上限。平台另有母校工作台與接待校文件資料。是否能由學生完成實際操作須另看瀏覽器流程紀錄。此盤點驗證資料關聯與欄位內容，未逐一取得所有海外承辦人的當期確認。
