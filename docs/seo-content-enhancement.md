# SEO 第二階段：內容與主題入口

依 SEO 科普建議修正公開頁面，不變更官方資料庫中的名額或資格。

- 總覽 H1 與 title 改為「全台大學」，母校數由 registry 產生，避免被誤認為臺大專頁。
- 方案和母資料相同的欄位只列一次；不同方案只列差異，來源不同時仍保留來源。完全相同的方案紀錄去重。
- 合作校頁有方案目錄、資格與語言、名額與年度、期限、學費住宿、文件課程等分區；既有句子與換行分段呈現，不改寫原始條件。
- 明確的「數字＋年份暫估」格式拆成來源數字與目標梯次暫估，前者年度／口徑未明就標為待確認；保留暫估原文，禁止相加，不推定當期正式名額。
- 每頁 title 與摘要指明母校、合作校、國家、方案數及資料狀態。保留自我 canonical、既有 URL 與返回選校工具的母校設定。
- 新增 `/destinations`、日本／韓國／德國三個專區；以各母校實際合作關係彙整，搭配授課、課程、住宿、生活預算與官方參考。未確認的費用不填數字，列表數量不是當期名額。
- 新增資格語言、費用補助、申請文件三篇原創指南及 `/editorial-policy`；與母校、合作校、國家頁互相連結。沒有虛構學生心得、作者經驗、校園合作或外部背書。
- 基本 sitemap 增加九個編輯頁；其他母校的合作校索引決策維持原狀。內容版型版本變動屬實質頁面更新，已建立基線的內容紀錄會反映此次變更。

來源連線檢查：JASSO、日本外務省、Study in Korea、Korea Visa Portal、DAAD、德國外交部入口回應 200；教育部海外留學資訊網在此環境回 403，保留其官方入口作為查閱連結，不宣稱已讀取其中公告或核定補助。

驗證包括全部 3,540 個合作校群組的模板渲染、SEO／品質／內容單元測試、手機與桌面免 JavaScript 瀏覽器驗收。這些檢查不代表 Google 已收錄新增頁面。

外部內容合作仍需真人經驗、授權與校方回覆。可向有意願的同學徵求「母校、合作校、交換年度、實際修課、費用項目、官方來源、可公開範圍」，審核與取得授權後再發布；可提供學校指南連結給相關校園組織，但不購買或批量張貼反向連結。本次未代發合作邀請。
