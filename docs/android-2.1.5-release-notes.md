# UniWay 2.1.5 測試版：深層表單與詳情頁改版

- 表單分成「填寫內容、附件、確認事項」，增加欄位圖示，縮短重複說明。
- 儲存、PDF、預算與論壇送出按鈕固定在底部，不必捲到頁尾。
- 學校詳情改用一致的玻璃卡片，完整校名、五個資訊分頁、收藏與官方來源更容易找到。
- 申請設定、共用資料、列印包、資格初判、文件檢查與改寫，使用相同的字體與操作方式。
- 整理日曆、社群、小工具及驗證畫面；修正窄螢幕與放大文字時的選單溢出。

## 安裝更新

1. 已有 2.1.3 或更新版本：開啟「我的 → 檢查更新」，點「下載更新」。
2. 也可直接下載本頁的 **UniWay-2.1.5-preview.apk**。
3. 在手機開啟下載的 APK，依 Android 提示確認安裝。可直接覆蓋舊版，不必解除安裝。

Android 7.0 以上；版本 2.1.5 / 19，套件 `tw.uniway.app`，沿用既有簽章。
SHA-256 請見附件 SHA256SUMS.txt。

帳號及服務沿用 https://app.uniway-tw.com/，本次不需更新 Jerry 後端。
沒有新增大學資料查核。Firebase 遠端推播仍待設定；實體手機登入及同步仍待使用者驗收。
