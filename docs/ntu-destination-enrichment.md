臺大目的地補充資料（2026-10-08）

正式網站的臺大 288 項合作校原本只有 17 項照片、14 項已核對座標。這次在可審查的分支補入校園照片、校級代表座標，以及離線可讀的合作校官網生活原文。沒有執行 Supabase migration、合併主分支或部署 Render。

這些數字不是「288 校全部資訊已更新」。各校不同生活面向、費用年度、住宿保證及錄取校區仍有缺口。282 項名額待公告、6 項零名額的招生狀態保留。

[逐校缺口表](ntu-destination-gaps.csv) 包含全部 288 項的中文／英文校名、國家、照片與定位缺口、已有／缺少生活面向、原文網址、成功查閱日期、失敗網址，以及需要確認的事項。[查核收據](../sources/ntu/destination-receipt-2026-10-08.json) 列出 2 項照片缺口、19 項座標缺口及 3 項無生活證據的學校。

照片逐張檢視；標誌、人物／活動主體、錯校區、PDF／影片縮圖及無法核對署名的候選沒有採用。Commons 照片保留作者、授權、原圖頁與裁切說明，來源標示為校園照片而非一律稱為官方照片。學校與國家共同決定照片身分，避免不同國家的同名學校相互覆蓋。

座標以合作校官方網域和國家交叉比對 ROR，再採用 Wikidata 的學校點位。ROR 的城市中心沒有作為學校座標。明確的 preferred 點位可作為校級代表位置；同一建築的重複點位可核對，不同校區不取平均。加州大學及加州州立大學等多校區體系保留待確認。巴黎高等農業學院的舊巴黎點位沒有直接沿用。

生活資料是官網原文節錄，保留完整段落、來源、原查閱日期及適用性說明，沒有推定交換生一定符合一般國際學生條件。查閱日期不代表官網更新日。2026/2027-1 價格沒有當成 2027-2／116-1 價格；醫療保障額度沒有當成生活支出。部分來源本次回傳 503，保留 2026-10-07 的成功來源與日期，另記本次失敗；沒有將保留內容重新標成最新。

程式預先載入生活原文，過去查詢失敗留下的空快取不會覆蓋這些來源。讀取頁面不因翻譯待完成而觸發背景擷取。操作者仍可明確點選「更新資料」。校級官網內容不隨地圖點位修正而消失，附近設施資料仍會在校區座標變更時失效。

重建資料不需要對正式服務寫入：

```bash
.venv/bin/python -m scripts.build_ntu_destination_enrichment
.venv/bin/python scripts/build_ntu_catalog.py --output-dir /tmp/ntu-catalog-review
```

前者從已審查快照重建共用照片清單、座標、臺大生活原文及精確綁定的翻譯，先核對照片 SHA-256。後者也可重建新增的 student_life.jsonl。來源快照與收據在 sources/ntu；位元組雜湊用來保留來源與輸出對應。

輸出是候選資料，須核對校區、照片內容及授權後才納入快照。TLS 驗證保持開啟，沒有使用官網截圖冒充校園照片。檔案可續跑，失敗查詢保留成功來源的日期；離線重播用 --offline。歷史資料只能作為原日期的參考，不宣稱已確認現行年度。
