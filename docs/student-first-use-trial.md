# 首次使用學生試用

狀態：尚未執行（2026-10-02 補入任務 7–9，對應文件一路完成、預算比對與變更影響）。這份腳本準備真人驗證；自動化測試或開發者自行操作不能填成完成。

## 對象與環境

請未使用過 UniWay、正在考慮校級交換的學生，用自己的手機或電腦試用。使用隔離測試帳號與資料；不要求提供真實成績單、護照或其他私人文件。記錄裝置、視窗寬度、試用日期，以及測試帳號的本校。引用當期來源不足的案例時，應保留待確認狀態。

主持人只說明任務，不指出按鈕位置。每項任務先讓學生自行探索；需要提示時，記下提示內容與發生時間。

## 任務

1. 「你打算明年交換。找到兩間值得繼續考慮的學校，說明為什麼適合，以及還不能確定的條件。」觀察是否知道先填條件、未考語言仍能探索，以及資格待確認與不符合的差別。
2. 「把兩所學校排成準備志願，保留其中一所的官方來源供日後確認。」觀察候選、比較、準備志願、文件目標的區別是否清楚，是否重複填個人資訊。
3. 「每週有六小時能準備，週二和週六可用。告訴我們接下來要做什麼。」觀察是否找到時間設定、理解共用任務與各校分支，以及缺工時或期限時知道怎麼處理。
4. 「一項文件工作還剩一小時，但需要先等系辦回覆。更新安排，再指出哪一項工作可以先做。」觀察等待、依賴與重排結果是否可理解，是否誤認系統排程改動官方期限。
5. 「從任務繼續填寫對應文件，找到第一個還沒填的必填欄位，再返回準備清單。」觀察是否到正確學校、年度、表格；不要用真實私人附件。
6. 「重新開啟網站，找回剛才的志願、進度與下一項工作。指出哪些內容仍須向校方確認。」觀察回訪能否延續，不將保存、匯出或完成勾選誤認已送件或錄取。

7. 「這份讀書計畫從頭做到可以列印。想想看，下一步是什麼？」觀察文件頁的「一路完成」進度條是否被看見、學生是否知道「下載 PDF」不等於已送件、選擇性的「檢查成品」「私人保存」是否被誤認為必做。
8. 「你每月預算大約三萬。看看哪所學校在預算內，並說出你有多確定。」觀察學生是否看懂「無法比對預算」的原因、是否把「在預算內」誤讀成「負擔得起」，以及是否注意到不含學費與機票。
9. 「學校官方公布新版規定後，你收到通知。找出哪些準備工作受影響，並決定先做什麼。」需要研究者先在隔離資料中發布一次更新。觀察學生是否看懂「請重新確認已完成的工作」，以及是否誤以為系統已改了自己的進度。

## 驗收

學生應能自行找到下一步、返回原工作、辨識個人安排與官方期限，並辨識來源缺口。卡點須記錄、修正並重新試用；不能僅憑滿意度問卷或自動化通過宣稱全流程完成。不記錄不必要的個資；錄影前由參與者同意。
