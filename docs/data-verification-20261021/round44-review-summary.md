# 成大116-1簡章查核與修正（第44輪）

本輪已將成大116-1六頁官方簡章的查核結果套用至本期97個合作方案，以及對應的流程、目的地介紹與母校共用資料。主修正2,064處，重複顯示追查另修正582處；保留舊值與來源頁碼。

已修正的主要資訊：

- 大學部以前一學期平均77分或班／系排名前50%擇一，移除自行換算的GPA替代門檻；研究所無最低成績門檻，但仍須指導教授同意。
- 申請期為2026年10月30日至11月19日16:00，未自行指定開放小時；同一學制可再次申請不同接待校，不能寫成每學制僅限一次。
- TOEFL舊制72／新制4、IELTS Academic5.5、TOEIC785及成績效期分開表達；其他外語須符合接待校採認，不能把任一有效級數視為合格。
- 文件截圖暫代、正式成績補驗、錄取確認與保證金期限／減免條件均保留。簡章同時出現免印紙本與照片簽章掃描要求，操作細節仍列待確認。
- 接待校學費有依協議另繳的例外；返國兩個月內以電子郵件寄送Word／PDF心得、成績單與問卷，不能寫成上傳系統。
- 役男校內行前程序依簡章為出國一個月前；各國簽證與現行兵役法規仍須各自核對。
- 獎學金金額須查另訂公告；未驗證的生活費保留為明確標示的原參考估算。

系統現在只對具相符來源證據的116-1方案套用本期母校資格，並分開檢查接待校學制。畫面提供平均分數或班／系排名；不再以GPA通過成大母校門檻。

驗證：58項Python回歸測試通過；最後補上年度時窗防護後，17項成大專項再次通過。前端實際函式通過9個成績案例與13個欄位斷言，JavaScript語法及Git差異檢查通過。這些不等於瀏覽器視覺驗收或全部事實查核。

新增2,444個原值綁定；202處沒有最初盤點中的對應欄位，獨立記錄並由固定雜湊的修正檔保存原值／原不存在狀態。累計123,544條決策的原值與檔案完整性檢查無錯誤；計數不是獨立已驗證事實數。

尚未完成：本期97校的接待校完整條件、五所來源矛盾、住宿／生活費／圖片／位置與獎學金細則；另114筆歷年參考資料未冒充本期規則。整體25母校與4,585合作方案的逐筆完整查核仍在進行，尚無整校或整筆全欄完成認定。尚未commit、push、建立PR或部署。
