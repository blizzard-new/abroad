# 第 35–38 輪資料核對結果

本輪完成指定欄位與資料來源年度的修正，尚未完成 25 所母校及全部 4,585 筆合作方案的逐項事實核實。整筆方案、整所大學的完整核實數仍為 0；PR 尚未建立。

## 臺師大：名額年度與學程條件年度混用

建置器將 116-1、115-2、115-1 的學程依名稱合併，原畫面沒有保留各學程的來源年度。依三份存檔及實際程式盤點 236 所合作校：

|學程條件來源|校數|本輪判定|
|---|---:|---|
|只有 116-1 學程資料|45|仍須逐項查核，不能視為已驗證|
|116-1 與歷年學程混合|10|標示跨期，仍須查本期適用範圍|
|只有 115-2／115-1 學程資料|134|不得當成 116-1 現行條件|
|三份存檔均無學程細節|47|缺少學程條件，仍須補查|

已修正上述含歷年資料的 144 所合作校，共 2,698 個欄位位置（不是 2,698 個獨立事實），涉及合作校資料 144 列、申請流程 144 列、目的地介紹 142 列。所有原值保留，重跑不會重複加註，也不覆蓋獨立更新。其餘兩列目的地介紹沒有命中這批已識別的學程文字，未套用此修正。

資格檢查與推薦也會辨識跨期標示。臺師大的母校學籍資格與接待校學制現在分開判斷，母校通過不能取代接待校條件確認。

本輪再查臺師大官方 API 雖收到 HTTP 200，內容卻為 S9910、body=null，沒有取得新的名額資料。本輪年度判定以可追溯的既有官方資料存檔為依據，並非即時名額確認。

## 早稻田：依授課語言、學部與入學季分開

已讀完 2027 一般簡章 16 頁、英語大學部條件 7 頁、日語大學部條件 10 頁及 JLP 1 頁。英語與日語學部各條件表及 JLP 已完成視覺核對；一般簡章的指定關鍵頁也已核對。研究所英語 14 頁與日語 15 頁仍待完整查核。

修正包括 CJL 分級 1–7、部分課程超額才抽籤、一般交換與 JLP 的學分限制不同，以及各學部的語檢與 GPA。日語法學部只收四月入學；日語教育學部只收四月且須一年；英語 JCulP 只收九月。這些接待校條件不會自動取代各母校提名規則。

臺師大早稻田條目的 116-1 存檔名額為 --、學程為空，網站原先合併 115-2 五組與 115-1 兩組條件，還有日語學部誤連英語附件等問題。已修正 22 個相關欄位位置，區分歷年參考、2027 接待校條件及尚待確認的母校要求。其餘 12 所母校的方案適用性已列於範圍表，尚未全部完成核對。

## 學生心得來源
