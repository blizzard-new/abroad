# 外部來源與人工確認清單（External Confirmation Checklist）

更新時間：`2026-10-22`
涵蓋範圍：全臺 31 所母校（原始 25 校 + `main` 新增 6 校）、4,956 筆合作方案列、2,775 所不重複海外接待校（`shared_host_factsheets.json`）。

本清單彙整**無法僅憑公開網頁自動消除**、必須由各校國際事務處（OIA）內部系統、SSO 登入專區或新學期正式簡章公告才能最終拍板的項目。平台對以下項目均採取 **Fail-Closed（誠實揭露、不偽造當期已核實狀態）** 原則。
