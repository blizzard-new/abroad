方案識別原本把同校的一般、語言密集、自費方案視為同一筆生活指南。修正儲存、查詢、欄位補充、審查與發布查找後，25校原始4,585份指南在執行時全部保留，修正前為4,583份；4,533個流程不變，現有資料未再發現儲存識別碰撞。機構照片及校級身分仍維持原有識別方式。[修正前](round46-route-identities-before.json)及[修正後](round46-route-identities-after.json)均保留。
