# 第47輪：輔仁申請表、三個自費方案與建置保護

本輪完成輔仁116-1申請表要求的資料修正，補入東洋、南山、同志社三個獨立自費方案，並修正學校清單仍顯示234筆的同步問題。查核分支的輔仁資料現在為237筆方案；遠端GitHub main本輪抽讀仍為234筆。這些變更尚未推送或部署，也尚未建立PR。

原始範圍為25所母校、4,585筆合作校／交換方案；此次依已讀官方附表另發現3筆，查核範圍增為4,588筆。原始盤點保持不變，新增方案另列[3筆補充查核表](additional-partner-review-progress.csv)，其原始盤點ID留空，不假造原始紀錄。計數單位是母校下的方案列，不是不同海外機構數。

申請表修正共2,591處，涉及468列既有合作方案／流程及7份共用JSON。新增三方案時，原有3檔共702列保持不變；新增方案未複製一般交換的免學費敘述，沒有將未核實的生活預算、校區位置或照片寫為已確認。這2,591處是套用到多筆資料的欄位修正數，不是2,591個獨立事實全數核實。

覆蓋率API會按方案列計算共用校級圖片，因此顯示237筆圖片覆蓋；這不能解讀成237個方案的實際校區照片都經獨立核實。三筆新增原始資料的圖片仍為缺漏、位置仍為空值。這項執行時顯示與來源證據的差異保留為後續查核事項。

## 驗證結果

175項相關測試通過，耗時159.41秒，涵蓋新方案查找、一般／自費方案隔離、申請表必備與條件式簽章、舊更新程序不覆寫後續查核、缺輸入時不寫檔，以及既有資格、內容與API路徑。另有前端方案查找檢查、OpenAPI一致性、186份Python檔案語法與Git差異格式檢查通過。[完整執行紀錄](round47-final-validation.json)。

先前兩次針對性測試各為39通過、1失敗：第一次揭露學校清單仍使用234筆的舊計數；第二次是圖片覆蓋測試未反映同校不同方案共用圖片的既有行為。兩者已處理後才執行175項完整相關測試，沒有隱去失敗紀錄。

25校實際執行時可載入4,588份方案指南、4,536份流程，原始資料與儲存識別分組未再發現碰撞。[本輪方案盤點](round47-current-route-census.json)。這是結構與查找驗證，不是內容真實性認證。

查核帳冊補入2,347個可對回原始盤點的欄位綁定；另244處原盤點沒有對應欄位，保留為未綁定，變更前值或原先缺漏另存於固定雜湊紀錄。全帳冊126,730筆決策、17,480個被綁定紀錄驗證無錯誤，原始21部分帳冊的串接雜湊維持不變。第一次寫入後的保留性檢查因JSON空白序列化規格不同而停止；改用原收據同一序列化方式後確認702列均未改變，已寫入決策逐項比對一致，再執行重跑確認沒有重複追加。[欄位綁定與恢復紀錄](round47-form-ledger-validation.json)。
