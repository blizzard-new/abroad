# 第43輪：成大116-1合作校表逐列核對

本輪完成成大官方一覽表16頁、97個合作校列的文字與版面核對，並將完整條件回填到合作校資料、申請流程與修課說明。這證明的是**母校表格列了什麼**；接待校當期規定、個人申請資格、圖片、地點、生活資訊及其他欄位仍須分別查核。整筆合作方案、整所大學的全面核實仍為0。

逐校結果見 [97筆查核清單](round43-ncku-partner-table-audit.csv)。CSV為UTF-8 BOM，已重新讀取確認97筆，適合以Excel開啟。

## 已完成的修正

- 97筆合作校、97筆申請流程及97筆目的地說明，共3,589個指定欄位修正；另同步8個統計與查核狀態欄位。數量是欄位變更數，不能當成獨立事實數。
- 補回被截斷的語言、GPA、院系及專業背景條件；完整原文與頁碼另外保存。早稻田的語言句原先被截斷，但禁止跨領域的限制原本已出現在其他欄位，不將其誤報成全站遺漏。
- 區分母校通用學籍門檻與接待校所收學制，不再直接把成大的碩博士資格套用到每間接待校。九州工業大學的大學部、研究所語言條件分開保留。
- 名額與一學期研習期限有母校表格證據；接待校條件與校內報名時窗保持待確認。本輪稍後新讀的甄選簡章提供時窗證據，尚待下一輪同步修正。
- 申請流程僅核對過母校名單條件的部分不再顯示成整份已發布／全部核實；目的地檔案改為部分查核。未改動其餘114筆歷年或合作參考列。
- 舊值保存在各列的 `reference_data`，修正使用精確原值比對，重播不覆蓋後續獨立編輯。資料產生器已接入同一修正程序。
