# 第45輪：維爾紐斯、秋田跨母校來源核對

本輪核對兩所接待校的指定來源，對應9所母校、12筆合作方案，修正合作校、申請流程及生活指南共36列的164個欄位，另補3個費用適用性欄位。這是部分欄位查核，整筆／整校完整核實仍為0。25所母校與4,585筆方案的完整查核仍在進行，尚未建立PR。

逐案結果見 [12筆查核表](round45-vilnius-akita-audit.csv)。原始值、來源網址、內容雜湊與修正理由保存在 [主查核紀錄](round45-vilnius-akita-review.json) 及 [費用適用性補充](round45-cost-applicability-followup.json)。

| 接待校 | 對應母校 | 本輪核對範圍 | 仍需確認 |
|---|---|---|---|
| 維爾紐斯大學 | 臺大、中央、臺師大、中山、北科、成大、陽明交大、清大、文藻 | 現行交換申請頁的語言、提名、文件與選課規則 | 指定梯次、雙邊協議、母校條件差異、完整課程及生活費 |
| 秋田大學 | 臺大、北科、成大 | 2027年4月簡章指定頁、2026/9/3合作名單、未標梯次的總覽 | 2027秋／2028春規則、當期配額、成大學位限制矛盾、完整表單與課程 |

維爾紐斯接待校頁列TOEIC聽讀785，成大母校表寫「讀寫785」，兩份原文分開保留。清大校內甄選不接受TOEIC的限制仍保留。臺師大表列ITP543，而接待校頁未明列ITP，不能自行認定接受或拒絕。接待校的一般博士選課規則也不能解除各母校協議的學位限制。陽明交大及文藻的115-2歷史方案沒有被轉為當期開放。

秋田的2027年4月簡章與未標梯次的總覽，對AUGP日語及AUSF語言條件有差異。成大只列AUGP／AUSF及一學期，不能以兩學期AUAJ補入可選方案。合作名單只證明列名，沒有當期招生配額。春季期限未寫入秋季期限欄或確定提醒。

費用參考增加獨立的來源、頁碼及適用狀態。預算比較與資料完整度會把未確認適用梯次的費用標為待確認，不會只因2027這個年份較新就判定符合預算。成本來源也改為指向實際費用簡章，避免引用前四個不相關來源。沒有新增費用證據的舊資料，其序列化不新增空欄位，以維持既有審查雜湊。

未變動其餘5,784筆資料列，也未變動這12筆方案的母校學年度、梯次、名額、學位與截止日期欄位。重播應為0變更；個別獨立後續修訂保留。原始盤點可綁定133個欄位，其餘31個主修正欄位與3個新費用欄位在原盤點不存在，不虛構原始null證據。全帳冊驗證為123,677個決策、17,008個原紀錄綁定、0錯誤；這不是123,677項事實已核實。

擴大檢查另發現 [輔仁方案識別碰撞](round45-fju-route-collision-followup.json)：原始234筆生活指南，在執行時合併為232筆。聖心女子大學的一般／語言密集課程，以及梅光學院大學的一般／自費方案，共用同一識別碼。這項問題尚未修正，下一輪須處理方案識別及其查詢／顯示路徑，並檢查其他母校是否有同類情況。
