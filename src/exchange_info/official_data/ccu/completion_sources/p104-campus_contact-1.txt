Imprint Imprint Ac­ces­si­bil­i­ty This website uses the Open Source Content Management System Plone and has been developed to work in accordance with the Web Content Accessibility Guidelines (WCAG 2.0). If this website does not conform with the standard or is not fully accessible in any respect, please contact the website manager . Accessibility statement We make every effort to use our knowledge and our understanding regarding the way in which different people access the Internet to ensure this website is as clear and as easy to use as possible for all visitors. Standard compliance We have used XHTML 1.0 and CSS, which follows the W3C specification, as we believe that usability and accessibility require a solid foundation. If any aspect of this website does not conform with the standard, please contact the Website manager . We also make every effort to achieve AA status in accordance with the accessibility guidelines specified by the WCAG 2.0. However, we are aware that a number of points in the WCAG can be interpreted in a variety of ways.
