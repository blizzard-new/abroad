The validated official name is Czech name Univerzita Pardubice . This identifier is valid for participation in HORIZON EUROPE projects and other Community programmes (e.g. ERASMUS+) where a PIC code is required. By using the PIC code, basic data about the organisation (registered office, status, VAT number, etc.) are automatically filled to the project application forms.  The Legal Appointment Representative (LEAR) is responsible for keeping the organisation's data up-to-date, LEAR  for UPCE is Ing.
