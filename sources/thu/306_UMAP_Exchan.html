計畫說明
  1. 亞太大學交流會（簡稱UMAP）為促進亞太地區高等教育領域學生交換，與其他會員國之學術與文化交流，建構亞太大學交流會交換學生計畫（簡稱USCO）。
  2. 此計畫共計3項：
    1. UMAP多國交換學生計劃Program A（UMAP Multilateral Student Exchange Program 簡稱UME）
    2. UMAP雙邊交換學生計劃Program B（UMAP Bilateral Student Exchange Program 簡稱UBE）
    3. UMAP特殊課程交換學生計劃Program C（UMAP Student Exchange on Special Courses 簡稱USC）。
  3. 參與UME計畫(Program A)可享有學雜費減免之優惠，每校可推派兩名學生至會員國之USCO參與學校交換，或接受兩名其他會員國之USCO參與學校學生。
  4. 網址：http://umap.org/             

 

本校甄選人數

2

 

UMAP會員校限制與課程資訊 

usco2.umap.org

 

申請資格/限制

申請資格：同 交換生申請資格。

選填志願：請至UMAP計畫網站確認欲申請之計畫。

 

繳交文件

除本校要求外，其他繳交文件及錄取資格以 UMAP Program A&B會員校要求為主，請自行瀏覽，usco2.umap.org。

以下資料僅提供申請 UMAP Program A&B 之計畫參考用。

  1. 備審資料：請依下列順序由上而下排列
  2. 東海甄選線上報名表(按我下載)及完成UMAP USCO 線上系統報名。(點選確認操作說明)
  3. 歷年英文學業成績單及班排名（含勞作成績；碩士班無勞作成績者，應提出操行成績證明）
  4. 外語檢定成績證明（英語：IELTS/ TOEFL iBT ；日語：JLPT ）
  5. 報名費：新臺幣500元整（請先行至國際處領取繳費單後至出納組繳交）

備註：

(1)英文語測證明  : 申請者需符合各會員校特殊語言要求之能力檢定。-會員校課程以英語授課者，均須檢附英文檢定成績，達下列其一標準，始可參加校內申請：

TOEFL iBT 79(含)以上。

IELTS 6.0(含)以上。

TOEIC 750(含)以上(僅參考)。

-以上成績，需於當次申請截止日前仍在兩年有效期內。

-UMAP會員校要求之英文檢定成績標準較高時，以UMAP會員校要求之分數為申請標準。

-申請時至少須有網路成績，僅完成報考但未有成績者不得申請。

(2) 獎學金發放以UMAP官方決定，資訊將另行提供給獲選同學。

(3) 選送上之學生需另外提供其他相關資料

 

申請截止日

2023.04.03-2023.04.20

有意報名者，請務必事先與國際處聯繫並填妥線上報名表單，以利於系統截止日前完成手續。
