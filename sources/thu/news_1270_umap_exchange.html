公告║亞太大學交流會（簡稱UMAP）交換計畫甄選

2026-02-26 林明姍

1. 計畫說明：

（１）亞太大學交流會（簡稱UMAP）為促進亞太地區高等教育領域學生交換，與其他會員國之學術與文化交流，建構亞太大學交流會交換學生計畫（簡稱USCO）。

（２）此計畫共計3項：

  • UMAP多國交換學生計劃Program A（UMAP Multilateral Student Exchange Program 簡稱UME）
  • UMAP雙邊交換學生計劃Program B（UMAP Bilateral Student Exchange Program 簡稱UBE）
  • UMAP特殊課程交換學生計劃Program C（UMAP Student Exchange on Special Courses 簡稱USC）

（３） 參與Program A者享有學雜費減免之優惠，每校可推派兩名學生至會員國之USCO參與學校交換，或接受兩名其他會員國之USCO參與學校學生。

（４）網址：http://umap.org/        

２．本校遴選計畫人數: 2人

３．UMAP會員校限制與課程資訊：usco2.umap.org

４．申請資格/限制

  • 申請資格：同 交換生申請資格。
  • 選填志願：請至UMAP計畫網站確認欲申請之計畫。

 ５．繳交文件：

（１）除本校要求外，其他繳交文件及錄取資格以 UMAP Program A&B會員校要求為主，請自行瀏覽，usco2.umap.org。

（２）以下資料僅供申請 UMAP Program A&B 之計畫參考用。

  1. 備審資料：請依下列順序由上而下排列（歷年英文學業成績單以及班排名／外語檢定成績證明，請繳交紙本資料至國際處）
  2. 東海甄選線上報名表(按我下載)及完成UMAP USCO 線上系統報名。(點選確認操作說明)
  3. 歷年英文學業成績單及班排名（含勞作成績；碩士班無勞作成績者，應提出操行成績證明）
  4. 外語檢定成績證明（英語：IELTS/ TOEFL iBT ；日語：JLPT ）
  5. 報名費：新臺幣500元整（請先行至國際處領取繳費單後至出納組繳交）

 ６．報名流程：

　請同學在3/28~4/20期間先填妥校內線上報名表單(按我下載)及完成UMAP USCO 線上系統報名。(點選確認操作說明)，完成線上報名後，

   煩請同學於3/28至4/20期間繳交以下紙本文件至國際處，並至國際處領取繳費單後，至出納組完成報名費繳交(新台幣500元整)。

     (1)歷年英文學業成績單及班排名（含勞作成績；碩士班無勞作成績者，應提出操行成績證明）

     (2)外語檢定成績證明（英語：IELTS/ TOEFL iBT ；日語：JLPT ）

7.  附註：

(1)英文語測證明  : 

申請者需符合各會員校特殊語言要求之能力檢定。-會員校課程以英語授課者，均須檢附英文檢定成績，達下列其一標準，始可參加校內申請：

  • TOEFL iBT 79(含)以上。
  • IELTS 6.0(含)以上。
  • TOEIC 750(含)以上(僅參考)。

-以上成績，需於當次申請截止日前仍在兩年有效期內。

-UMAP會員校要求之英文檢定成績標準較高時，以UMAP會員校要求之分數為申請標準。

-申請時至少須有網路成績，僅完成報考但未有成績者不得申請。

(2) 獎學金發放以UMAP官方決定，資訊將另行提供給獲選同學。

(3) 選送上之學生需另外提供其他相關資料

８．申請截止日：2026.03.28-2026.04.20

有意報名者，請務必填妥校內線上報名表單，同時至UMAP線上申請系統( https://usco2.umap.org/)遞交申請資料（成績單, 語言能力證明, 動機信, 護照影本, 體檢證明) ，文件依學校規定會有所不同，請同學務必先至UMAP網站（usco2.umap.org）了解欲申請學校的文件繳交要求。

補充：申請系統簡介(學生端操作說明)https://umap.org/usco2_resources_for_students/

９．本案聯絡人：林明姍小姐（mingshanlin@go.thu.edu.tw）。

10.  聯絡電話：校內分機28502

有意申請UMAP計畫者，於UMAP系統遞交申請後，煩請來信告知國際處承辦人(mingshanlin@go.thu.edu.tw)，以利本處進行申請資料的確認。

因每校檢送參與UMAP計畫的名額有限(2名)，本處將依據學生的在校成績/語言成績選派參與UMAP計畫的學生。
