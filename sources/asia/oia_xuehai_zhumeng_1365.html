學海築夢/新南向

學海築夢 / 新南向學海築夢 申請資訊

「學海築夢計畫」是鼓勵學生至海外非新南向國家（不含中國大陸及港澳）之企業或機構進行職場實習。
「新南向學海築夢」鼓勵學生前往新南向政策目標國家（包括東南亞、澳洲等國）進行職場實習。

一、校內申請時程

  1. 一年會有兩次申請機會。
  2. 上半年：約2～3月徵件，用於當年暑假起出國實習。下半年：約8～9月徵件，用於隔年出國實習。（實際日期依教育部公告及校內時程為準）

二、申請資格與條件

  1. 計畫主持人：由本校專任教師擔任計畫主持人，得聘共同主持人一名，共同主持人應為本校專任或兼任教師。
  2. 每一計畫主持人於學海築夢及新南向學海築夢計畫限各提送一案為原則。
  3. 選送人：須具中華民國國籍並設有臺灣地區戶籍，且為本校在學滿一學期以上之學生（不含在職專班生）。
  4. 學生須經系所審查並由計畫主持人推薦。
  5. 學生需具備專業能力與語言能力（英語需達多益550分以上，或其他語言能力達實習機構要求）。
  6. 獲補助經費出國之選送生，不得同時領取我國政府提供之其他出國補助。

三、選送生所需文件(如附件)

  1. 出國研習行政契約書.docx
  2. 聲明書.pdf
  3. 語言能力證明（多益或其他實習單位要求的檢定證明）
  4. 實習機構邀請函或錄取證明（實習機構同意書參考範本，英文版需含實習期間、內容、負責人簽名等資訊）

四、審查標準

         (一)課程內容 60%

  1. 實習課程規劃之完整性。
  2. 實習內容與學系發展之切合性。
  3. 選送人數及計畫經費之合理性。
  4. 計畫開放其他學系學生參與之歷年紀錄。
  5. 其他有利條件(如符合校務發展等)。

        (二)機構條件 40%

  1. 實習機構與選送生所學專業能力關聯性。
  2. 實習機構之聲譽、資源提供以及實習合作條件(如膳宿提供、工作津貼等福 利)。
  3. 實習機構對於實習生之輔導與考評機制。
  4. 實習機構過去留任本校學生擔任正式職務之紀錄。
  5. 實習機構提供之其他有利條件。

五、補助內容與期限

  1. 實習期間至少應連續30天（赴印尼至少25天），不含交通日，最多可補助至一學年內。
  2. 補助至少包含一張往返國際經濟艙機票（一次），另可包括生活費，具體金額由學校依計畫內容分配。
  3. 須於補助核定後至隔年10月31日前辦妥出國手續並啟程，否則視同放棄補助。

六、注意事項

  1. 計畫主持人與學生出國前須簽訂行政契約書。
  2. 回國後兩週內需上傳心得報告（中英文，1000字內）、照片4張與3分鐘影片至教育部平台，否則無法完成計畫結案。
  3. 若變更實習機構，需重新經由本校國際事務處審查並核可，一次為限。變更實習機構未經本校同意者，將喪失受補助資格，本校將追償已領補助款，並繳還教育部。
  4. 各子計畫構想頁(每一申請案需附 1500 字至 2000 字摘要，包括赴國外實習機構簡介、效益、向教育部申請經費、本校提出配合經費及預計選送學生人數)。
  5. 計畫主持人應自行聯繫國外實習機構，不得藉助或委託仲介公司辦理。


如需進一步了解或申請學海系列計畫，請至各系所或國際事務處(L105)諮詢。
