114學年度出國交換甄選開放申請

The application for the 2025-2026 academic year outbound exchange is now open.

1. 申請期限至114年2月18日(二)下午17:00

2. 甄選面試日期：114年2月24日(一) 第7〜8堂

溫馨提醒 :

1.歷年成績單(總表，非單張形式)與歷年成績排名證明書(學士生)預計114年2月可開始向註冊組申請辦理。

2.確定可申請後，除了到校臨櫃申請，亦可善用郵寄申請，請詳閱郵寄申請方法與留意郵寄時程 :https://reg.nptu.edu.tw/p/412-1066-3191.php?Lang=zh-tw

3. 「學海惜珠」申請者報名時需檢附相關之有效身分證明文件。

----------

114學年度出國交換甄選現已開放申請。歡迎瀏覽簡章與準備報名文件，並於期效內申請。

如有修正、補充或解釋事宜將另行公告。

The application deadline is February 18, 2025.

The application for the 2025-2026 academic year outbound exchange is now open. Feel free to review and prepare the required documents,

and submit your application within the specified period. OIA will announce If there are any updates or corrections.
